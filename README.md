# META SKILLS

Публичная библиотека авторских игровых скилов META GAMES. Оригинальные инструкции и переносимые скрипты: `packages/<name>/skills/`.

Для автозадач: прочитайте `catalog.json`, затем оригинальный `SKILL.md` нужного пакета. Проверяйте наличие зависимостей и реальное исполнение. Исходные бинарные ресурсы, неразрешённые сторонние материалы и секреты не публикуются. Импорт выполняется поэтапно; исходники без всех зависимостей не считаются полностью готовыми к исполнению.

## Skill Nexus: развитие скилов

При работе над улучшениями скилов читайте `catalog.json`: поле `skill` задаёт основной SKILL.md, а `additional_skills` — дополнительные модули того же плагина. Для `skill-synergy-manager` модуль `nexus-oss-evolution` описывает поиск и проверку open-source, интеграцию, сохранение качества и согласованную публикацию в ChatGPT/GitHub. Скрипт `scripts/oss_upgrade_gate.py` проверяет метаданные кандидата, но не заменяет CI, визуальные испытания и проверку лицензий. Изменения в ChatGPT требуют отдельного доступного авторизованного Plugin Creator; GitHub snapshot сам по себе не обновляет ChatGPT. Не считайте PR релизом `main` до слияния.
