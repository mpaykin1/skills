# META SKILLS

Публичная библиотека авторских игровых скилов META GAMES. Исходные инструкции и переносимые скрипты размещаются в `packages/<name>/`.

Для автозадач: прочитайте `catalog.json` (после публикации), затем оригинальный `SKILL.md` нужного пакета. Соблюдайте зависимости, лицензии и требования исходника; чтение инструкции не является исполнением. Используйте только доступные инструменты и проверяйте реальные результаты. Не размещайте секреты и сторонние материалы без права распространения.

Репозиторий инициализирован; перенос пакетов выполняется поэтапно.
