# Sprite Sheet Helper → META GAMES compatibility

- Upstream: https://github.com/Kyonru/sprite-sheet-helper (MIT, © 2026 Roberto Amarante); pinned `aacb362aa35e4fec8102f7d08e9955d65c03eb88`, `package.json` version 0.8.3.
- Actual official CLI `dist/cli/index.js` generated with `npm run build:cli`. The browser compositor uses Puppeteer/Vite and reads original 3D GLB geometry/animations; build-time only. No direct sprite-stack PNG input is claimed.
- Inputs: source `.glb` directly, with actual original animation tracks preserved; `stack.json` via existing official `sprite-in-the-round` exporter to GLB; four-view PNG via previous danielwh2 module then `sprite-in-the-round` to GLB. The intermediate mesh is a *derivative* of original volume; not an original Godot/Unity skeleton or gameplay.
- Outputs: `atlas/` from actual CLI; default generic spritesheet PNG + JSON. Official `--format godot|unity|phaser|gif|zip` offers alternatives. `--workflow three-quarter-8dir` captures 8 views of one real volume. `--fit auto` fixes one framing across all directions and all sampled clips to avoid changing hero scale.
- `--frames` controls sampling of existing clip timing; does NOT invent motion in static stacks. For authored per-pose stacks use previous `stack_to_html.py` with separate full frame stacks. Original PixiJS takes explicitly approved PNG frame atlases; it is a distinct renderer, not a GLB-animation importer.
- Godot Shader-Stacker continues rendering actual horizontal slices in native 2.5D; the new export provides 8-direction prebaked images for games instead, not a replacement for shader stack sorting or full-volume Three.js 360 raymarch.
- Playwright/Pixelmatch checks visual parity in the target renderer. Khronos glTF Validator checks source/intermediate GLB, but cannot establish pixel fidelity or recovered animation identity. Check transparency, silhouette, color and pivot against the original, especially under postprocessing.
- Safety: Keep source originals immutable; reject mismatched files, missing tools and empty atlases; input scope is authorized game assets. Source, legal marks and LICENSE maintained separately. No final HTML/game runtime dependency on Puppeteer or Vite.
