# Правила владельца: META GAMES → Playgama

Приоритет: новая точная команда владельца > свежие AGENTS.md/GPT.md и действующее управление репозиторием > эти ранее закреплённые пользовательские требования. Правила безопасности, разрешений и защищённых путей не отменять.

1. **Источник:** `mpaykin1/meta6/playgama-catalog`, а НЕ отдельный `meta6-lab/preview/.../claude-games/`.
2. **Первая:** новая игра/обложка — **позиция №1** во всех вариантах.
3. **Обложка:** только та, которую пользователь отправил для новой игры, либо проверенная официальная; полноформатная, чёткая, подходящие пропорции, правильный alt, файл принадлежит проекту; не делать фейковые обложки.
4. **Только Playgama:** `cover`, `title`, `play` кликаются и **без любых промежуточных страниц** ведут на конкретный `https://playgama.ai/play/<siteId>`; не предлагать второй игровой адрес или локальное превью.
5. **Локали:** EN, DE, JA, KO, FR, ES, PT-BR, RU; все обновляются синхронно; переводить тексты каждой карточки и метаописание.
6. **Существующие игры:** без потери, дубликатов, изменения старых Playgama URL, случайного перемещения; порядок всех прежних игр сохранён.
7. **Жанры:** добавлять новую игру в релевантные категории и обновлять только существующие страницы; прямые ссылки — и здесь.
8. **SEO:** настоящие title, description, OG/Twitter, canonical/hreflang, JSON-LD `CollectionPage` + `ItemList` и `VideoGame`, позиции и количество, sitemap `lastmod`, проверенный cover, нет несуществующих отзывов, статусов, рейтингов или фактов о механике.
9. **Лор:** под ENTER THE DREAMVERSE — локализованный отрывок сюжета Зерна последнего мира; клик открывает полную историю на том же языке. Текст лора не заменять промо-текстом. Лор не является промежуточной страницей запуска игры.
10. **Проверка:** визуально ПК+телефон, реальная кликабельность/переход Playgama, HTTP 200 источника и обложки, зелёный CI. Не путать успешный git merge с опубликованной страницей.
11. **Контроль:** только бесплатные инструменты; не менять ядро игры, эталоны, проверки/охранники, рекламу.
12. **Минимум ручного труда:** пользователь даёт обложку и ссылку, всё остальное скилл выполняет автономно через доступные подключённые инструменты; если авторизация запрещает действие, не заявлять успех.
