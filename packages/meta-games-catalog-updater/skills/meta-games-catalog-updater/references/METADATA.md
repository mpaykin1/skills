# Входные данные и алгоритм изменения

`game.json` создаётся по указанной владельцем Playgama-ссылке и изображению, а не из догадок. Обязательные поля:

- `title`: точное публичное название.
- `slug`: латинский URL/имя обложки, уникально (`a-z0-9-`).
- `playgama_url`: точный `https://playgama.ai/play/<siteId>`; перед применением сверить источник и URL.
- `genres`: один или несколько **существующих** разделов `action, adventure, horror, arcade, story`.
- `verification`: например «ссылка и публикация подтверждены владельцем»; не заявлять проверку Developer Console без доступа.
- `locales`: ключи `en`, `ru`, `de`, `fr`, `ja`, `ko`, `es`, `pt-BR`; для каждого `tag`, `description`, `alt`, `aria`, `seo`, опционально `genre_intro`.

Не указывать абсолютный адрес обложки: скрипт ставит локальный файл в `playgama-catalog/covers/<slug>.<ext>`. Изображения создаются только из предоставленного оригинала. Скрипт **не загружает обложку из интернета** и не совершает GitHub push. При отсутствии изображения работа останавливается.

## Преобразование

- HTML: копировать существующую первую карточку как структурный шаблон, меняя её имя/URL/tag/description/alt/aria/изображение. У трёх ссылок одинаковый URL Playgama. Существующий первый элемент становится вторым с `loading=lazy`.
- JSON-LD: новая `ListItem.position=1`, прежние позиции +1; `numberOfItems` = фактическое число карточек; не добавлять дополнительные «придуманные» сущности.
- SEO: локализованные meta description, OG/Twitter, `og:image` = новая обложка, название и счётчик. `canonical` и `hreflang` — те же собственные адреса, что и раньше; sitemap пополнять только реальными индексируемыми страницами.
- Жанры: аналогичное добавление по существующему шаблону, но не выдумывать отдельные страницы игры.
- Инвентарь: новая запись в `pendingGames` (если Playgama подтверждена лишь владельцем), либо в `games` только при наличии достоверной записи Developer Console; по умолчанию сохранять все прежние записи и статус.
- Идемпотентность: если название+slug+Playgama URL уже стоят первыми, проверить целостность вместо создания дубля.

## Не делать

Не использовать числовые константы для числа игр. Не затирать существующие картинки; не менять старые Playgama URL; не создавать `playgama-catalog/games/<slug>/`; не добавлять `playgama.ai/play` в sitemap; не удалять `lore.html`; не подменять `owner cover` выдуманной иллюстрацией; не объявлять публикацию без подтверждённого live.
