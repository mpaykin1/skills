# Vulkan Validation Layers + Lavapipe
Official https://github.com/KhronosGroup/Vulkan-ValidationLayers (Apache-style Khronos license). Use signed Ubuntu packages vulkan-validationlayers, mesa-vulkan-drivers, libvulkan-dev, glslang-tools, spirv-tools, gcc. Record installed versions. Canonical bridge https://github.com/mpaykin1/skills/tree/nexus/vulkan-validation-20261127/packages/skill-synergy-manager/skills/vulkan-validation-bridge/. Reuses exact prior successful Lavapipe source at 2b30e4b58b6529f1fc668adc87f58ef8dd68e838; do not fork independent renderers. The wrapper enables VK_LAYER_KHRONOS_validation, debug-utils callback and synchronization validation explicitly. Valid native offscreen draw/readback must have zero error callbacks; controlled invalid VkBuffer size=0 must be intercepted with actual VUID, never submitted to driver. CPU only. Do not suppress VUIDs or turn off checking to get green.
Run on a disposable trusted worker via scripts/run_validation.sh /absolute/path/to/approved/lavapipe/scripts. For actual engine use native Vulkan debug mode and explicit validation layer, inspect real error messages; do not assume fixture validates a game. GPU-assisted validation is not enabled or verified. Browser WebGL uses glslang ESSL, WebGL Lint and Spector.js separately; native Vulkan uses glslang -V, spirv-val, Lavapipe and VVL; RenderDoc is optional compatible native capture. llvmpipe remains the native OpenGL route. Performance measurements must run without instrumentation and on real target devices. No inference of mobile FPS from CPU.
Route actual VUIDs using scripts/route_errors.py: synchronization, image layout, barriers and lifetime to Game Style Forge and Godot Game to HTML; shader/pipeline errors to glslang/Forge; texture and descriptor issues to Forge/Godot, inspect GIMP/Sprite Stacking source alpha only when implicated; geometry/buffers to Blender/Fusion when asset-related. Nexus coordinates one source-preserving fix and repeats same scene/camera/seed/time. Never alter approved hero poses, textures, native gameplay or Rapier physics, protected meta6, or ship instrumentation. Do not report visual improvements without actual game frames.
