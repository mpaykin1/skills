# WebGL Lint + Spector.js + RenderDoc
WebGL Lint 1.11.4 (MIT), pinned source https://github.com/greggman/webgl-lint/tree/fb9b1c61d2fc6467f844447d8fd0f953c02aee92. Original bundle and license in vendor/. Canonical runner and vendor: https://github.com/mpaykin1/skills/tree/nexus/webgl-lint-20261126/packages/skill-synergy-manager/skills/webgl-lint-bridge/
Use only authorized local development copy, isolated network and no credentials. Install pinned Playwright dependency in scripts/; run `node lint.mjs http://127.0.0.1:8765/ '#game'` with actual game running. It injects original WebGL Lint before page scripts, collects actual exceptions/console errors, and returns nonzero for failure or missing instrumentation. It instruments main-thread canvas only; worker contexts need their own explicitly instrumented debug build. No global ignoring uniforms, errors or disabling checks to fabricate success. For expected shader probes document narrow exception in a separate debug copy. A clean observation window does not prove a game is fully correct.
Separate browser processes: (1) WebGL Lint before initialization, strict errors and NaN/unset uniforms; (2) Spector.js on unmodified debug scene to inspect selected draw calls, textures, framebuffers; (3) uninstrumented Playwright and real device measurements for frames and FPS. RenderDoc is separate native-only path. Never combine the two API wrappers in one context or ship them in release. Actual visual nonempty frames, animation and controls remain mandatory under animated-world/black-screen guards.
Route shader/uniform/framebuffer errors to Game Style Forge, bad textures/alpha to GIMP and Sprite Stacking, buffer/index errors to Blender/GLB validation and META Game Fusion; compare same scene, camera, seed, time, resolution. Do not replace approved heroes, change source files, Rapier physics or protected meta6. One fix at a time. No claims of FPS gains without measurements. Reuse the canonical runner rather than duplicating implementations across plugins.
