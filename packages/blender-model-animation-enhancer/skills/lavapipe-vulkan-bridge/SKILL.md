# Mesa Lavapipe CPU Vulkan
Source https://docs.mesa3d.org/install.html and https://gitlab.freedesktop.org/mesa/mesa . Canonical executable probe: https://github.com/mpaykin1/skills/tree/nexus/lavapipe-cpu-20261127/packages/skill-synergy-manager/skills/lavapipe-vulkan-bridge/scripts .
Install signed Ubuntu packages mesa-vulkan-drivers libvulkan-dev glslang-tools spirv-tools gcc. On disposable Linux x86_64 worker use scripts/run_cpu_vulkan.sh; chooses only installed Lavapipe ICD (lvp_icd*.json) via VK_DRIVER_FILES and VK_ICD_FILENAMES, compiles original fixture GLSL to Vulkan SPIR-V, validates it, renders a triangle into offscreen RGBA8 image and reads center/background pixels. Requires VK_PHYSICAL_DEVICE_TYPE_CPU and llvmpipe/lavapipe device name. Record actual installed versions. Technical fixture is not game art or proof of engine rendering.
Pipeline: glslang ESSL syntax/link validation for WebGL (without -V); for native Vulkan only glslang -V + spirv-val -> Lavapipe Vulkan draw/readback; llvmpipe EGL/OpenGL is a separate route. Godot Forward+/Mobile may run under Lavapipe only if real required features and native scene rendering succeed; use Godot's actual renderer, camera, original GDScript and physics in a disposable copy. Godot headless can be dummy rendering; Web export remains Compatibility. Blender Cycles CPU remains offline render authority; Vulkan viewport support depends on Blender version and driver, no blanket compatibility claim. Preserve source GLB, RGBA, rig, full-frame poses, lighting and texture identities; no placeholder production assets. RenderDoc may replay native compatible captures, not guaranteed with software ICD. WebGL Lint, Spector and normal Playwright run separately under browser renderer, not this Vulkan ICD. No GPU performance inference from CPU timing.
Skill Nexus routes native shader/pipeline issues to Forge, model/rig to Blender, texture/alpha to GIMP and Sprite Stacking, source game export to Godot Game to HTML; compare same seed, time, camera, resolution, source hashes. Use validated software backend only where appropriate. Preserve all prior guards and protected meta6. No instrumentation in release. One concrete repair, no invented improvement percentage.
