# Infinigen integration
Upstream: https://github.com/princeton-vl/infinigen (BSD-3-Clause). Source is not redistributed in this package. Use Indoors 1.x documented branch `indoors-stable` rather than the changing V2 preview API. See https://github.com/princeton-vl/infinigen/blob/indoors-stable/docs/Installation.md and https://github.com/princeton-vl/infinigen/blob/indoors-stable/docs/HelloRoom.md. Install in an isolated Python 3.11 environment with upstream OS prerequisites. Clone `--branch indoors-stable`, record `git rev-parse HEAD`, and install `INFINIGEN_MINIMAL_INSTALL=True python -m pip install -e .` for indoors. Do not silently substitute V2. Nature requires the full upstream terrain installation and its own documented CLI.

Generate: `python scripts/generate.py --repo /path/to/infinigen --python /path/to/env/bin/python --out /path/to/new/output --room LivingRoom --seeds 10 11 12`. Optional `--fast` for rough previews. Each seed gets its own folder. The script invokes the real upstream Python module, checks the output, and records the commit. No mock outputs.

Director: `blender -b /path/to/scene.blend --python scripts/director.py -- --focus Piano --out /path/to/new/directed --plan /path/to/plan.json --mood noir`. Focus must be an existing exact object name. Plan optional: `{"movable":["Chair.001"],"keepouts":[{"min":[-1,-4,0],"max":[1,4,2]}],"seed":4}`. Units and coordinates are Blender world coordinates. Only independent static unparented mesh objects are eligible to move; specify whole assemblies as protected instead. Never include walkable floor, walls, ceiling, doors, structural meshes, or objects with attached gameplay state as movable. Existing camera remains unchanged; new scene camera is used for the preview only. Existing lights are preserved; tune added lights after inspecting exposure. Area lights are authoring tools, not direct glTF punctual light equivalents. Output is a separate scene and PNG; use actual runtime checks before shipping.
