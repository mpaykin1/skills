# Nevergrad — closed-loop optimization
Upstream: https://github.com/facebookresearch/nevergrad (MIT). API: https://facebookresearch.github.io/nevergrad/optimization.html and https://facebookresearch.github.io/nevergrad/parametrization.html. External offline dependency, not bundled or installed in browser builds. Use a separate compatible Python environment (e.g. Python 3.11), `python -m pip install nevergrad numpy`; record resolved versions; lock versions after real end-to-end run. Never fake a render or optimization if dependencies are absent.

Pipeline: Infinigen generates separate seeds (or existing authorized scene) -> director.py creates protected staging and three authored lights -> BlenderProc renders seven existing fixed recipes -> best feasible fixed recipe seeds bounded Nevergrad NGOpt -> ask/tell receives loss from actual RGB, focus mask and depth -> re-render finalists at higher samples and additional animation frames -> apply_recipe.py writes only selected light energy and size to a new .blend. Nevergrad never replaces Infinigen spatial constraints or BlenderProc renderer. No new scene if editing existing art. The existing refine.py remains a cheaper alternative.

Run: `python scripts/optimize.py --scene /path/directed.blend --focus Piano --cameras 'CSD Preview Camera' 'Gameplay Camera' --frames 1 --validation-frames 1 30 60 --budget 16 --out /path/new-opt --blenderproc /path/render-env/bin/blenderproc --blender /path/blender`. Choose only frames where focal object is intended to be visible; supply extra frames for animation generalization. With just one frame, validation is only a higher-sample render, not held-out temporal validation. Cost scales with views × frames × candidates; start with small budget. All candidates render from the same unmodified input with absolute multipliers, never cumulative transforms. Fail closed on subprocess errors or missing passes; do not apply unrendered recommendations. Keep baseline and director as independent comparisons. Validate candidate in each view and worst-view score, not average alone. Source scene remains unchanged.

Current search space: key/fill/rim energy multipliers and shared area-light size. Camera poses, direction and object placement are authored by director.py and evaluated across views, not optimized by NGOpt in this version. Infinigen seed selection still needs independent geometry/route review; compare validated recipes across layouts only with comparable views, same artistic brief and protected constraints. Metrics are technical proxies, not proof of aesthetic quality; inspect actual frames and gameplay after selection. Do not ship if navigation, asset identity, color grading, motion or mobile budget regresses.
