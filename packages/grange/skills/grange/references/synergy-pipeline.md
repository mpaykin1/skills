# Grange: реальные компоненты и единый шлюз

- MobileSAM: https://github.com/ChaoningZhang/MobileSAM — официальный ViT-T, локальный checkpoint.
- SAM 2: https://github.com/facebookresearch/sam2 — официальный Python API SAM2ImagePredictor, совместимый checkpoint/config.
- Mapbox Pixelmatch: https://github.com/mapbox/pixelmatch (ISC); npm pixelmatch@8.0.0 + pngjs@7.0.0 (MIT); `npm install --ignore-scripts` в scripts/.
- rembg: https://github.com/danielgatis/rembg — локальный u2net, исключительно подготовка alpha для непрозрачного источника. Не перезаписывать исходник.
- RIFE: https://github.com/hzwer/ECCV2022-RIFE — commit 5d8adbdd40e12c2c8f91930eff838aebe561c086, официальный matching `flownet.pkl`. Только транспорт/эффекты, один ракурс/действие; промежуточные кадры не утверждены.
- OpenCV: https://github.com/opencv/opencv — явная регистрация масок/анализ траектории. Pillow + NumPy: прежний П22. FFmpeg/ffprobe: https://ffmpeg.org — независимое декодирование; не изменяет проверенный GIF.

Установить реальные зависимости в отдельном окружении, согласно совместимости официальных версий/лицензиям; не имитировать наличие модели. Опциональные rembg/RIFE не нужны для исходных прозрачных независимых кадров. Сегментация двух моделей проверяет утверждённую маску; отдельно сохранённая утверждённая маска допустима без моделей, с явным указанием режима. Pixelmatch и FFprobe обязательны. Источник моделей не включён в ZIP; на момент сборки MobileSAM, SAM2, rembg и Pixelmatch в текущем контейнере не установлены, RIFE checkout/weights не подтверждены.

Команда подготовки (при необходимости): `python scripts/prepare_candidates.py SRC NEW --kind rigid-transport --single-action-view --rife-repo REPO --rife-weights WEIGHTS --loop`. Для непрозрачного исходника добавить `--rembg`; без него opaque кадр блокируется. Кандидаты затем собираются `assemble.py`, проверяются визуально; при удвоении кадров корректировать задержки, чтобы длительность цикла не менялась. Никаких новых автоматических approvals.

Шлюз: `python scripts/synergy_gate.py manifest.json` (предварительный), затем `python scripts/synergy_gate.py manifest.json --publication` (закреплённые raw URL). Все пути в манифесте абсолютные, кроме масок внутри action_json, которые по прежнему чекеру относительны к нему. `candidate_frames` — один объект для каждого декодированного кадра; `reference_frames` — для всех кадров эталона; `ref_indices` — нумерация с нуля. `body_mask` — PNG L с белым корпусом. Для ручной маски — реальное утверждение и `approved_mask_sha256`. При dual-model проверке задать `segmentation` с `mobile_checkpoint`, `sam2_config`, `sam2_checkpoint`, `device` и в каждой записи `prompt` с `box:[x0,y0,x1,y1]`, `points:[[x,y],...]`, `labels:[1,0,...]`. `registration_xy` — явное смещение кандидат→эталон; `registration_scale` только для прыжка после независимого П10. `allowed_edit_mask` (в координатах эталона) и `approved_edit_sha256` только при заранее согласованной локальной правке. `reference`, `candidate`, `approved_reference_sha256`, `ref_indices`, `action_json`, `regression_dir`, `candidate_raw_url`, `visual_review_sha256`, `visual_review_approved:true` (только после осмотра фактических кадров) обязательны для выпуска. `once` для одноразовых действий, `rigid` только для жёсткого ракурса. Нельзя подделывать approval. `regression_dir` — распакованная историческая actions/ из архива Bullet Car; проверяется по точным хэшам. Для других заказов переиспользуй эти глобальные контрольные негативные примеры, не заменяй их текущими кадрами. Порог П22 не зависит от масок, Pixelmatch или ffprobe. При недоступном raw, отсутствующих масках или библиотеке — BLOCKED. Ничего не изменяет в GitHub автоматически; публикация отдельным разрешённым действием только после шлюза.

## P29–P30: structural similarity and tracked texture continuity
Install genuine `scikit-image` and `opencv-python-headless` in the same Python environment as the existing gate (or reuse existing compatible OpenCV; don't install two competing cv2 packages). Sources: https://github.com/scikit-image/scikit-image (BSD-3-Clause), https://github.com/opencv/opencv (Apache-2.0 for current versions). `texture_motion_gate.py` is imported by `synergy_gate.py`, not an independent release route. P25 masks feed P30; P23 registered protected region feeds both Pixelmatch and P29 SSIM. P30 uses genuine GFTT + pyramidal LK with forward/backward validation, local SSIM in tracked 7×7 patches, and timestamp-aware reversal checks, including the loop seam. No resampling of the deliverable. Strict fixed-view gates must not be applied as universal pose-change classifiers. New outputs are `P29_ssim` and `P30_optical_flow`. Numeric gates never replace inspection. P22 remains the original Pillow RGB calculation and pinned GitHub checker. Run `python scripts/texture_motion_regression.py /path/to/approved.gif` on a textured, sufficiently large, transparent original. Negative cases are derived copies in memory, not replacement art. Historical regressions still required separately.
