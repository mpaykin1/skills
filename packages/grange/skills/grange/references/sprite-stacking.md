# Sprite Stacking × Grange

Общий рендер: `python scripts/stack_pipeline.py recipe.json OUT`; `OUT/animation.gif`, `OUT/frames/`, `OUT/body/`, `OUT/parts/`. `python scripts/stack_pipeline.py recipe.json OUT/animation.gif --verify` повторяет рендер и сравнивает байты. Для воспроизводимости фиксируй версию Pillow/NumPy и входные файлы. Никакая автоматическая проверка не создаёт художественный эталон и не выдаёт утверждение.

Прежде чем рендерить, создай реальный авторский текстурированный mesh (Blender) или согласованные срезы; если референс неполный, реконструированный объём требует визуального утверждения. Для каждого стека `stack.json` содержит `layers` (относительные пути PNG RGBA снизу вверх), `layer_sha256` (по одному на слой), `spacing:[dx,dy,dz]`, `pivot:[x,y,z]` (локальный pivot относительно центра объёма). Все части в общих мировых единицах, RGBA alpha>=128 означает occupancy; это непрозрачный объём, не интегратор дыма. Срезы получают цвет поверхности/материала из исходного UV, не независимую текстуру по ракурсам. Не использовать копирование одного силуэта. Простые цилиндрические элементы с постоянным сечением должны иметь реальную форму торцов или быть частью более полного авторского стека; не обходить проверки поддельными срезами. `radius` — единая половина ширины/высоты ортографического холста в мировых единицах; увеличить её для всего согласованного набора, если есть обрезка, а не менять от кадра к кадру.

Схема recipe (сокращённый пример, не готовый ассет):
```
{"schema":"grange-stack-v1","source_art":"approved.blend","source_art_sha256":"<sha256>","size":320,"aa":2,"radius":3.2,"duration_ms":90,"parts":[{"id":"body","role":"body","stack":"body/stack.json","stack_sha256":"<sha256>"},{"id":"wheel","role":"body","stack":"wheel/stack.json","stack_sha256":"<sha256>","translation":[1,1,-0.5]}],"frames":[{"camera":[0,65],"parts":{"wheel":{"rotation_deg":[90,0,0],"translation":[1,1,-0.5]}}}]}
```
Реальный рецепт содержит 12–24 разных поз с корректной периодической траекторией без дублирования последней; `camera` = yaw,pitch в градусах; `rotation_deg` = локальные X,Y,Z (Rz Ry Rx), `translation` = мировой pivot; координаты поз абсолютные. Вложенные части заранее вычислить через иерархию жёстких матриц, а не деформировать спрайты. `kind: authored_pose` разрешает заменить стек части на другой **полный авторский** стек в записи кадра с отдельным SHA; для rigid запрещено. Роль effect исключается из body при наличии body. Для независимого эффекта без корпуса весь видимый объём является маской. Сохранить маски частей, затем сверить действительные кадры и сформировать action JSON для П10. Не применять маски к П22. Для 8 направлений одна модель, разные рецепты с тем же pivot/radius, физически согласованными позами и фиксированным светом. Отдельный поворот 360° можно распределить на 24 кадра для Grange либо на 36+ по явному запросу и отдельному формату, не ослабляя лимиты по умолчанию.

`synergy_gate.py` вызывает проверку `stack_pipeline.verify` перед остальными шлюзами. Отдельно утверждённые маски, segmentation и визуальный контроль прежних правил не удаляются. Манифест: `production_route: sprite-stacking`, `stack_recipe: path/to/recipe.json`. Для реально утверждённого исключения `production_route: approved-2d-exception`, `stack_exception: approved-original-2d|soft-volume-effect|organic-authored-poses|explicit-user-2d`, `stack_exception_approved: true`, `stack_exception_reference_sha256: <actual approved reference hash>`. Не выставлять approval автоматически. Совместимость с прежним серверным шлюзом: он не знает П38–П43, поэтому до обновления сервера нужны обе проверки, по одним и тем же байтам. Отсутствие доказанного объёмного источника не превращать в PASS.

## Автоматическое создание исходных стеков и траекторий (0.1.12)
Для максимального применения технологии используй эти два инструмента как подготовку к **единственному** stack_pipeline.py, не как альтернативный рендер. При наличии согласованного UV- или vertex/face-colored меша нарезай его автоматически: `python scripts/mesh_to_stack.py model.glb body --resolution 256`. Требуются Trimesh, NumPy, Pillow. Реальное плотное барицентрическое семплирование поверхности в XY-срезы по Z, без выдумывания скрытой геометрии, без заполнения внутренних полостей. Выход — PNG RGBA и stack.json со всеми SHA256 слоёв, spacing, pivot, source_center_world. Раздельно нарезанные части должны использовать общий физический шаг; по возможности экспортируй из Blender с едиными единицами, не нормализуй объекты под один размер. Source center используется для восстановления правильного положения частей. Для тонких деталей выбирай достаточное разрешение. Не считать такой автоматический срез визуальным утверждением. Сложные материалы/освещение предварительно запечь в согласованную текстуру; внешний арт и его текстуры сохранить вместе. При наличии только эталонного GIF нельзя автоматически восстановить точную 3D-модель, сначала создать и утвердить реконструкцию. Существующий принятый GIF не переделывать.

`python scripts/stack_motion.py base.recipe.json --mode drive8 --frames 16 --pitch 65 --tracks tracks.json` создаёт восемь рецептов с единым радиусом и исходными хэшами. `--mode orbit` — 360° без дублирования конечного кадра, `--mode fixed` — фиксированный ракурс. В базовом рецепте допускается дополнительное поле `parent` у части; её translation/rotation_deg тогда в координатах родителя. Генератор разворачивает иерархию в абсолютные rigid transforms каждого кадра (Rz Ry Rx), удаляет parent перед передачей каноническому рендереру. Пример tracks.json:
```
{"body":{"translation":{"amplitude":[0,0,0.02],"cycles":2},"rotation_deg":{"amplitude":[1.5,0,0],"phase_deg":25}},"wheel_FL":{"rotation_deg":{"turns":[1,0,0]}},"antenna":{"rotation_deg":{"amplitude":[4,0,0],"phase_deg":-45}}}
```
Только реальные части, физически правдоподобные вращения/фазы, не подстраивать амплитуду под числовой П22. Для одноразовых ударов, прыжков, поломок и органических поз задавать авторские траектории/полные позы в recipe. Вся финальная сборка через `stack_pipeline.py` и `synergy_gate.py`; точное воспроизведение GIF и все П0–П43 обязательны. Фактура должна оставаться живописной, без воксельных ступеней, дубликатов или подмены эталона. Для эффектов и ранее утверждённых 2D источников только предусмотренные П38/П42 исключения.
