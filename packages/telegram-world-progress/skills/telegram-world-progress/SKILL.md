## Цикл
1. Прочитать актуальный план, HEAD обоих репозиториев и PR/checks, точные обязательные проверки и deployed SHA. Получить сведения о живом Mini App, Telegram webhook, D1 и Supabase без секретов. Не читать чужие личные сессии. Если подтверждение недоступно, отметить unknown.
2. Для каждой задачи собрать снимок: `{id,repo,sha,status,criteriaVerified,requiredChecks,independentReview,verificationRefs}`. status planned/candidate/accepted/blocked; requiredChecks = массив `{name,sha,conclusion}` именно обязательных проверок. Независимое ревью другой компании обязательно. verificationRefs — ссылки на проверяемые runtime-факты, не произвольные заявления; критерий проверяется агентом перед заполнением. Если функция опубликована, её deployed SHA тоже проверить. Скрипт не добывает эти факты сам и не выдаёт их за доказательство. 
3. Запустить `node scripts/progress.mjs PLAN.json snapshot.json`, где snapshot содержит `{heads:{"mpaykin1/meta6-lab":"40hex","mpaykin1/World_server":"40hex"},tasks:[],runs:[{id,completed,acceptedDelta}]}`. Порядок: refresh → repair → verify → stalled → finish → complete. Процент только по принятым критериям, вес групп фиксирован. Старый SHA не подтверждает текущую версию. Повторный запуск с тем же ID не считается второй попыткой. При застое сменить способ устранения блокера. Не считать план, коммит, merge или одно HTTP 200 выполненной игровой функцией. Сохранять только минимальный статус в проектном реестре без секретов.
4. Использовать `nexus-automation-supervisor` и `nexus-project-operator` для инвентаря, ownership и реального действия. Не вызывать Symphonia-специфичный 14-stage gate с Telegram-снимком; здесь его адаптация с 34 задачами. Не редактировать чужие зоны, не ослаблять проверки.
5. Маршрутизация существующих скилов: A/G — Playwright из Meta Game Fusion + Animated World Guard; B/C/E — Meta Game Fusion, Game Style Forge, Hero Animator, Blender Model Animation Enhancer, Casual Game Studio, Animation Quality; D — существующий D1/Cloudflare и Supabase, серверная проверка; F — META Multiplayer Nexus (Trystero, Colyseus, Rapier, Nakama); музыка — MUSIC. Для GLB — существующие glTF Transform и валидатор, для NPC — существующие анимации и Rapier/Recast только при необходимости. При браузерной проверке — реальный рендер, действия, сохранение, два клиента, mobile portrait/landscape; без доступного устройства соответствующий критерий unknown. Не заявлять интеграцию на основании названия.
6. На текущем запуске выдавать процент, одну следующую задачу, настоящий блокер и проверенную ссылку, если опубликовано. Не публиковать логи, тестовые артефакты или handoff без запроса. Никаких платных сервисов.
