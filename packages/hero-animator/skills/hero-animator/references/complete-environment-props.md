# Цельные объекты окружения — обязательный контракт 0.19.0

Применять при создании/ремонте всех игр Hero Animator. Этот контракт дополняет требования к управлению, цельным кадрам персонажей и PNG multiview; не заменяет их.

## Не превращать край панорамы в отдельное дерево

Явно различать `background/panorama` и `complete-prop`. Фрагмент с края общей иллюстрации, обрезанной кроной, фоновыми полосами или неполным корнем нельзя размещать отдельными карточками в мире. Прозрачное поле вокруг такого фрагмента, размытие, fade, clamp/alpha-test или перекрытие другим деревом НЕ восстанавливают утраченную форму. Отсутствующие ветви/верхушки дорисовывать полноценным самостоятельным изображением в исходной художественной манере; источник сохранять. Новую художественную работу не выдавать за pixel-exact прежний арт и не ставить humanApproved без реального ответа пользователя.

## Обязательная проверка

1. Исходный самостоятельный PNG должен целиком содержать крону, тонкие ветви, ствол и корни. Нет обрывов на прямой границе картинки. Проверять RAW candidate ДО нормализации/добавления полей — иначе padding скрывает факт исходной обрезки.
2. Настоящий RGBA: снаружи прозрачность, внутри уверенно непрозрачный рисунок. Проверить на светлом/тёмном/нейтральном фоне: нет остатков прямоугольной панорамы, цветных полос и жирного ореола. Не заменять изображение программным деревом/кубами. Исходные нарисованные пиксели не деформировать.
3. Для органических силуэтов выполнять `prop_integrity_gate.py`: поля RAW не менее2%, финальные не менее5% (минимум4px), разумная площадь alpha, отсутствие длинных прямых обрубленных концов на внешнем контуре. Признаки — структурная эвристика, не доказательство художественной целостности: дополнительно смотреть весь силуэт. У архитектуры естественные прямые кромки не являются автоматически обрезкой; сохранять собственный PNG multiview-контракт и проверять исходный полный чертёж. Органический фильтр не подменяет архитектурную приёмку.
4. После проверки исходника технически добавлять прозрачные поля без crop/resize/deformation; кодировщик lossless сохраняет ВСЕ RGBA-пиксели, проверять декодированным сравнением. Если используется общий атлас, каждую ячейку проверять отдельно, предусмотреть padding/gutters и half-texel UV, не допускать соседние кадры в ветвях.
5. У самостоятельного объекта реальные width/height и root pivot. Не растягивать портретное дерево в квадрат. Корневую точку крепить к terrain, учитывать прозрачные поля и горизонтальный offset; проверять при повороте камеры. Статичное мёртвое дерево не «анимировать» подрагиванием всей карточки.
6. Регистратор props принимает только проверенные `complete-prop` записи. Панорама остаётся дальним планом, никогда fallback для отсутствующего prop. Если полного арта нет или проверка не прошла — остановить этот путь сборки и исправить ассет; не выпускать старую обрезку под новым именем.
7. В игре наблюдать объекты вблизи/вдали и при реальном перемещении/повороте камеры, на ПК и в portrait/landscape. Отдельно отличать естественный выход объекта за край ЭКРАНА от искусственного среза внутри его ИЗОБРАЖЕНИЯ. Проверять плавное затухание дальних объектов до освобождения чанка; не удалять деревья мгновенно в радиусе6м от героя. Дальняя панорама должна закрывать весь обзор при повороте: в legacy-адаптере используется fullscreen cover с сохранением пропорций и плавным панорамированием, без записи глубины; конечная мировая карточка не должна открывать чёрные прямоугольные края.

## Исполняемый путь

- `pack_environment_props.py SOURCES.json PACK.json` проверяет RAW, добавляет только прозрачные поля, сверяет RGBA после lossless WebP и сохраняет hash, роль, bbox, root pivot, происхождение и честную метку художественной приёмки.
- `repair_environment_props.py OLD.html NEW.html [--props PACK.json]` принимает фактическую автономную игру с исправленным управлением0.18.3. Проверяет каждый embedded prop повторно, исключает `old_oak/dead_forest/distant_ruins` из потокового props-слоя, встраивает полноценные изображения без CDN/fetch и сохраняет ASSETS/HERO_PACK byte-identical. Старые изображения внутри исходного ASSETS сохраняются как происхождение, но не используются отдельными props.
- `assets/complete-ash-props.json` — реальный встроенный комплект трёх целиком нарисованных деревьев. Его можно заменить собственным проверенным комплектом с теми же тремя зарегистрированными IDs; нельзя подменять отсутствующую картинку metadata-only заглушкой.
- `infinite_ash_game.py` и `repair_infinite_controls.py` используют этот этап автоматически перед финальным возвратом HTML. Прежний complete_ash_game.py — только промежуточный legacy этап, не готовый выпуск по новым правилам.
- `test_prop_integrity.py PACK.json OLD_GAME.html` проверяет положительные реальные деревья и отрицательные реальные старые атласы, фрагмент с искусственным padding, отсутствие alpha/визуального review и подменённый hash. Дополнительно запускать браузерную проверку: `test_environment_game.mjs GAME.html OUTPUT_DIR` и сохранённый input gate; количество текстур брать из runtime, не зашивать23.

Зависимости: Pillow (уже входит в общий графический конвейер). Не нужен платный API для проверки/сборки. Для подготовки новой графики использовать доступный Imagegen, не подменять bitmap иллюстрации SVG/Canvas примитивами. Художественное утверждение новых деревьев пользователем остаётся отдельным от технического PASS.
