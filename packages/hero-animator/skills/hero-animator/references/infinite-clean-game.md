# Обязательный игровой контракт — 0.19.0

Для декораций дополнительно обязателен complete-environment-props.md: только цельные отдельные изображения, проверка RAW до padding, корректные пропорции и root pivot; фрагменты панорам не размещать как props. В адаптере встроены три реальных проверяемых дерева, а старые обрезанные old_oak/dead_forest/distant_ruins исключены из props-слоя.

Управление уточнено `input-release-gate.md`: джойстик слева, отдельные кнопки справа opacity0.75; прежние скрытые правые жесты больше не применять.

Эти требования применяются ко ВСЕМ новым играм Hero Animator и ремонту игр, если пользователь явно не задал другой формат. Они уточняют прежние примеры с конечной ареной, кубическими стражами и экранными кнопками. Старые инструменты остаются доступными, но их старый UI не является рекомендуемым результатом.

1. Мир продолжается по +X, −X, +Z и −Z: детерминированные чанки земли И декораций, ограниченный активный кэш, освобождение GPU-буферов, одинаковая генерация при возвращении. Удаление невидимого барьера без продолжения земли — ошибка. Глобальные координаты не зацикливаются. До Float32 матриц применять floating origin. Победа не должна блокировать исследование мира.
2. Названия left/right означают направление взгляда НА ЭКРАНЕ, не анатомическую сторону тела. При камере с +Z ArrowLeft выбирает left и уменьшает X; ArrowRight выбирает right и увеличивает X. Проверять фактический лист и скриншот. Запрещено зеркалить асимметричный арт. Front/back также обязательны для всех действий.
3. ПК автоматически начинает игру; в игровом окне только графика, без DOM-кнопок, HUD, подсказок и стартового экрана. Управление описывать в отдельном README. Клавиатурные пауза и рестарт сохраняются.
4. На телефоне плавающий НЕВИДИМЫЙ джойстик появляется логически в точке первого касания левой половины: радиус56px, мёртвая зона9px, аналоговая величина. Не рисовать основание/ручку. Независимые pointerId для джойстика, боя и камеры. pointercancel/lostcapture/blur/hidden сбрасывают ввод. Отпускание правого пальца не сбрасывает левый.
5. Запрещены видимые примитивные кубические персонажи и модели-заглушки. Коллайдеры могут быть невидимыми. У каждого NPC полноценные отдельные кадры всех используемых действий/видов, собственный FSM и фаза. Качество не ниже героя: одинаковая художественная техника, разрешение, foot pivot, альфа и темп кадров. Повторное использование того же реального набора допустимо для однотипных противников, но должно быть явно указано; не обещать уникальный дизайн. Отличать противников светом/руной мира, не перекрашивать утверждённые PNG. Нельзя заменять отсутствующий арт кубом, покачиванием карточки или деформацией.
6. Из «Острова сумерек» заимствовать принципы: плавающий ввод, независимые касания, заполнение portrait/landscape, инерционное сопровождение камеры, пространственные слои, туман глубины, независимые угли/дым, читаемый сигнал подготовки удара, короткий причинный звук попадания. Не копировать CDN, чужие тексты-инструкции или полный экранный grade/glitch/bloom на героя. Количество эффектов не заменяет читаемость.

Проверять настоящий автономный HTML offline в браузере: четыре клавиши и четыре реальных ракурса, переход всех старых границ, лимит чанков/воспроизводимость, отсутствие экранных кнопок, бой/захват/бросок, мультитач/отмена касаний, портрет390×844 и альбом844×390, отсутствие внешних запросов/ошибок WebGL. Художественная приёмка каждого кадра остаётся отдельной; технический запуск её не подменяет.

## Исполняемый адаптер поставленной игры

`python scripts/infinite_ash_game.py ORIGINAL.html PACK.json OUTPUT.html --canonical CANONICAL.png`

Сборка использует существующий проверяемый `complete_ash_game.build`, затем обязательные исправления; исходный HTML не перезаписывается. Новый проект Three/Rapier по-прежнему использует основной физический конвейер, а этот путь сохраняет оригинальный legacy WebGL renderer и не заявляет о встроенном Rapier.

`runtime/infinite-world.js`: 24×24, 7×7 активных чанков; `runtime/invisible-controls.js`: настоящий pointer-ввод. Бой использует существующие 44×8 полнотелых кадров, противники — павшие странники того же облика с рунической меткой; это НЕ новый уникальный арт врагов. Нельзя менять human_reviewed_each_frame на true.

Телефон: невидимое левое перетаскивание — движение, максимальное отклонение — бег. Справа явные кнопки: удар, прыжок, взять/портал, захват (держать, затем удар для броска), уклонение, перекат, присед (держать), пауза, заново. Прозрачность25% = opacity0.75. Удержание джойстика неподвижно и касание пустой сцены не создают действий. ПК: WASD/четыре стрелки, Shift, Space, C/Ctrl, Q, F, J, G, E, Esc/P, R; touch-панель скрыта.
