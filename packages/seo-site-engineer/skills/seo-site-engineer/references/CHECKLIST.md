# Проверочный лист SEO

- [ ] HTTP 200 для всех заявленных продакшен-URL
- [ ] Единственный canonical; он совпадает с постоянным URL
- [ ] Preview noindex и отсутствует в sitemap
- [ ] Уникальные title/description и H1
- [ ] Контент соответствует реальному интенту и продукту
- [ ] Нет битых внутренних ссылок
- [ ] JSON-LD синтаксически корректен и соответствует видимому контенту
- [ ] FAQ не содержит выдуманных утверждений
- [ ] Собственные изображения, точные alt, width/height, оптимизация
- [ ] Корректные robots.txt, sitemap.xml, lastmod
- [ ] hreflang двусторонний, только для реально существующих языков
- [ ] Мобильная навигация, LCP/CLS/INP измерены при наличии инструментов
- [ ] IndexNow ключ и API подтверждены, если используется
- [ ] CI зелёный на актуальном SHA, защита не ослаблена
- [ ] Публичный HTML после публикации повторно проверен
