# SAM 2.1 → TRELLIS.2 → O-Voxel

Upstream: https://github.com/facebookresearch/sam2 (SAM 2 code and checkpoints Apache-2.0; other assets/dependencies can have separate terms). Install official upstream in isolated environment with matching PyTorch and verified checkpoint, e.g. `sam2.1_hiera_tiny.pt` with `configs/sam2.1/sam2.1_hiera_t.yaml`. Record upstream commit and model checksum. No weights bundled. CPU may be slow; GPU optional for SAM segmentation, required by our TRELLIS.2 adapter. Do not claim runtime availability without checking.

1. Agent inspects approved image and chooses individual objects (hero, creatures, tools, instrument, modular architecture). Prepare `objects.json` with real pixel coordinates, e.g. `[{"id":"harpist","box":[100,80,450,700],"points":[[260,200],[110,90]],"labels":[1,0]}]` (example coordinates, not actual reference). Use correct original image dimensions and positive/negative points to exclude occluders. SAM generates masks, not semantic labels or unseen geometry.
2. Run `python scripts/sam2_pack.py sam2 --image approved.png --objects objects.json --checkpoint /actual/path/sam2.1_hiera_tiny.pt --out segments --device cpu`. Without `--objects`, automatic candidate masks are generated and named candidate-NNN. Those candidates may overlap or represent fragments; review and label independently. For each candidate retain mask, exact crop and original RGB, source hash and model provenance. Review silhouettes, gaps, overlap warnings, thin structures and material transparency. A binary segmentation does not recover translucent material alpha. For accurate translucent objects import an authored grayscale mask instead.
3. External mask route: `python scripts/sam2_pack.py import --image approved.png --objects external.json --out segments` where `external.json` is a list like `[{"id":"harpist","mask":"harpist-mask.png"}]` and mask has original image dimensions. This is not SAM inference. Never invent masks or claim automatic segmentation occurred.
4. After agent visually reviews candidate crops, create `selection.json` such as `["harpist","harp","bridge"]`; run `python scripts/sam2_pack.py generate --segments segments --selection selection.json --out volumes --up z --size 256 --python /actual/trellis/env/bin/python --glb`. The wrapper verifies crop hashes and calls the existing TRELLIS.2 adapter once per selected asset. Choose native up axis from actual model, not assumption. No fake fallback. Generated geometry may need manual correction and rigging; complete the existing independent character actions, 360° views, scene.json, cover and catalog workflow. Only use the approved scene's object identities. All ready gates remain mandatory.
