# Blender Cycles — shared offline cover renderer
Upstream https://github.com/blender/cycles ; use Blender 4.5 LTS (https://www.blender.org/download/lts/4-5/) with its bundled Cycles, not an unrelated renderer. GPL licensing applies to Blender/Cycles; respect independent asset and dependency licenses. Do not distribute Blender binary in the plugin. CPU is supported but full scenes may take substantial time. No paid compute without permission.

`cycles_cover.py` reads the same RGBA slice PNGs or tiled atlases as the game. The actual source stack metadata, scale and spacing are kept. Each slice is a horizontal alpha-textured plane, not a generated replacement mesh. Use explicit bottom-center placement and `anchorOffset` to reconcile the asset pivot; use +Z up, +Y top of PNG. Use an elevated orthographic camera; horizontal stacks have edge-on and lighting artifacts (surface normals are horizontal-plane normals); do not claim mesh-equivalent PBR. Set author-approved constant roughness/metallic/emission per asset. Per-voxel PBR sidecars remain untouched and are NOT automatically shaded by this adapter; a later extension may project those maps per slice. For true fog use actual OpenVDB density grid in world coordinates, not RGBA alpha archive or density-slice alpha; separate effect asset with no collider. Preserve authored density transform. No density animation yet. Pose stacks use equal size, spacing, gridOrigin and pivot; motion is explicit integer-cycle object motion, not camera movement; actual articulated animation requires supplied full pose stacks from Hero Animator or Blender. Validate continuity between last and first frame visually. Never use a synthetic fixture as final art.

Scene schema `cover-pack-cycles/1`, paths relative to scene.json, 16:9, 2–8 seconds, up to four area lights. Example structure (paths must be real):
```json
{"schema":"cover-pack-cycles/1","fps":12,"frameCount":36,"resolution":[960,540],"samples":32,"camera":{"location":[6,-10,8],"target":[0,0,1],"orthoScale":9},"worldColor":[0.04,0.04,0.06],"worldStrength":0.25,"lights":[{"location":[-3,-4,7],"target":[0,0,1],"power":900,"color":[1,0.75,0.5],"size":3}],"objects":[{"id":"hero","stack":"hero/stack.json","location":[0,0,0],"scale":1,"motion":{"translateAmplitude":[0,0,0.03],"cycles":1}},{"id":"instrument","stack":"instrument/stack.json","location":[1,0,0]},{"id":"architecture","stack":"architecture/stack.json","location":[0,2,0]},{"id":"fog","kind":"density","vdb":"fog/density.vdb","location":[0,0,0],"densityScale":0.5}]}
```
For full poses add `poses:[{"frame":0,"stack":"hero/idle0/stack.json"},{"frame":6,"stack":"hero/idle1/stack.json"}]`; choose only approved independent frames; no fake deformations. Each object's `stack` can be a regular stack.json or compatible asset.json with an atlas. Maintain identical hero and approved art. `python scripts/cycles_cover.py --scene /path/scene.json --validate-only` checks inputs without Blender. `blender --background --factory-startup --python-exit-code 1 --python scripts/cycles_cover.py -- --scene /path/scene.json --out /path/frames` renders each frame and creates `/path/frames-frames.json` with source hashes and exact frame durations. Then `python scripts/webp_cover.py --manifest /path/frames-frames.json --out /path/encoded` creates a verified lossless WebP/poster, or use calibrated LPIPS optional lossy path. Compare matched views with LPIPS separately and route mask/geometry/material/environment/fog defects back to respective tools. Keep master renders and asset files. A render or successful encode alone never marks pack ready. Review on mobile and compare hero, architecture, palette and silhouettes against full catalog. No claimed rendering if Blender unavailable.

v0.15.0: default `--denoise off`; for explicit CPU OIDN guided candidate use `--denoise oidn --samples N` and follow [OIDN paired review](oidn.md) before libwebp. Keep source scene unchanged; compare full animation against higher-sample raw reference.

For new covers configure the shared [OpenColorIO contract](opencolorio.md) before Blender startup; render, denoise and encode with the same profile.
