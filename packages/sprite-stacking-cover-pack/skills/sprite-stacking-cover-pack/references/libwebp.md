# libwebp — lossless-first cover delivery
Upstream https://github.com/webmproject/libwebp (BSD-style license; check upstream notices), docs https://developers.google.com/speed/webp/ . Pillow with libwebp animation support, NumPy; LPIPS adapter and pretrained checkpoint only for lossy search. No upstream runtime is bundled. `scripts/webp_cover.py` uses the actual libwebp encoder through Pillow; it never changes geometry, PBR, RGBA stacks or scene assets.

Render the actual approved scene (SAM 2.1 → TRELLIS.2/O-Voxel, Infinigen, Material Maker, Open3D, OpenVDB) to independent full RGBA PNG frames at identical dimensions. Preserve source files. Create a manifest with `scene` (relative path to real scene.json), `sceneSHA256`, and `frames` array of `{ "path": "frames/000.png", "sha256": "actual hash", "durationMs": 100 }` for every rendered frame. 2–8 seconds, positive durations, 2–240 frames, maximum side 2048. Hashes are of actual files. Do not use image motion or a synthetic frame fixture as proof of live assets. Scene hash only links provenance; visual review still required.

`python scripts/webp_cover.py --manifest rendered.json --out optimized` tries lossless WebP, decodes it with libwebp, compares alpha and every visible RGB pixel at every time interval, checks exact loop duration and infinite looping. Identical consecutive frames may be coalesced without changing playback. Hidden RGB at zero alpha is not meaningful for display. Emits cover.webp, original first-frame cover.png and encoding.json with hashes, bytes and encoder version. If no valid candidate, keep sources. No automatic ready.

Optional `--max-lpips VALUE --calibration-id ID --budget-bytes N`: use thresholds calibrated on accepted/rejected real cover pairs; compare every corresponding decoded frame using existing LPIPS `Metric` and `prepare_pair`, light and dark alpha backgrounds, maximum distance. If LPIPS unavailable, run lossless separately; never fake a score. Try quality candidates and select smallest valid file with exact alpha/timing. No claim of minimum possible size or guaranteed improvement over GIF. A failed budget cannot authorize reduced quality. Review motion, small details, shadows, fog and loop seam visually. Compare with previous approved cover and catalog before publishing; route differences in encoding back to encoder, not to source art. Keep PNG fallback for reduced motion and unsupported browsers, use picture with WebP and existing approved GIF/PNG fallback, lazy load and explicit dimensions; verify mobile browser playback. Keep assets and chapter manifests intact; reference cover only after actual web publication and quality approval.

v0.15.0: OIDN render manifests are rejected unless the [paired OIDN review](oidn.md) has accepted the exact frame hashes. Compression remains a separate fidelity check; raw Cycles references can be encoded without denoising.

For color-managed scenes the encoder verifies the [OCIO contract](opencolorio.md) and bundle hashes. Input frames are already display-referred sRGB; do not reapply a display transform.
