# glTF Transform — animation-safe delivery candidates
Upstream https://github.com/donmccurdy/glTF-Transform (MIT); CLI https://gltf-transform.dev/cli . Use a verified installed 4.x CLI with dedup flags and meshopt support. Do not install packages from unreviewed sources or run paid infrastructure. The package contains an adapter, not the external CLI.

`python scripts/gltf_transform_pack.py --source source.glb --out animated-runtime` runs accessor-only deduplication, preserving materials, meshes, skins, textures. It compares embedded accessor bytes, skeleton and animation channels, morph targets, node transforms, geometry and image payloads. This intentionally rejects unsupported/sparse/multi-buffer or reordered inputs, and may reject semantically equivalent rewrites. It is not a complete glTF validator. Add `--meshopt` to try a separate compression candidate; quantization may alter geometry, and the strict structural audit can reject it. Compressed accessors are not decoded by this audit, so do not claim animation equality. No candidate is produced if the check fails or size does not improve. No animation resampling, simplification, pruning or automatic texture transcoding. Keep source for unsupported inputs.

Both modes produce the existing runtime-mesh.json contract with source and candidate hashes. Use runtime_mesh.mjs and the same Three.js release, MeshoptDecoder and optional KTX2Loader. Select optimized GLB only after actual decoding, compare the same animated poses and intermediate times (idle/run/attack/hit/death, skeletal weights, morphs, loop boundaries, attachments, collision and root motion), LPIPS and visual review. Require explicit approved hash. Sprite Stacking RGBA, O-Voxel, Open3D, OpenVDB, source materials and collision proxies remain canonical. Basis Universal independently compresses sprite textures; no second lossy transcode. Infinigen and TRELLIS.2 supply meshes; Material Maker supplies reviewed PBR data; Cycles renders original scene; libwebp optimizes its frames. No claim of execution without installed CLI or browser. The next validation layer should use Khronos glTF Validator on both source and candidate; it does not replace decoded animation comparison.
