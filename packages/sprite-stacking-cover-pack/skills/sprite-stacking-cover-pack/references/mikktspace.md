# MikkTSpace — static hybrid tangent basis
Official upstream: https://github.com/mmikk/MikkTSpace (retain upstream license notices). Build CPU bridge from the official, unmodified `mikktspace.c` and `mikktspace.h`, pinned to a reviewed commit. Linux example: `cc -O2 -fPIC -shared -I /path/MikkTSpace scripts/mikktspace_cpu.c /path/MikkTSpace/mikktspace.c -lm -o /path/libcover_mikk.so`. No substitute tangent generator or GPU required. The adapter uses genTangSpaceDefault and retains per-corner tangent.xyz and handedness w; it does not weld corners across seams. Requires reviewed unit per-corner normals matching exact xatlas OBJ triangle order in +Z-up source world axes, not guessed smoothed normals. Converts source axes to glTF +Y up with proper rotation and OBJ UV to glTF top-down before tangent generation. Preserve original UV, normal map and geometry separately. Only static hybrid assets; never replace canonical sprites, animated/morph/skinned assets or collision data.

`python scripts/mikktspace_pack.py --atlas /path/uv-candidate --review /path/review.json --library /path/libcover_mikk.so --out /path/tangent-candidate`

Review JSON requires atlasSHA256 (hash of uv-atlas.json), cornerNormals (relative .npy with shape F×3×3), cornerNormalsSHA256, alphaMode (OPAQUE/MASK/BLEND; MASK requires alphaCutoff). Supply roughnessFactor/metallicFactor in [0,1] only if missing from atlas maps. Optional normalMap (relative RGB PNG), normalMapSHA256, normalConvention `glTF-MikkTSpace-Y+`, normalBakeMeshSHA256 and normalBakeCornerNormalsSHA256 matching exact mesh and normals. The author must actually bake this map for the target UV/tangent basis; hash binding is not proof of correct baking. Use Blender Cycles or reviewed external bake, convert normal-map conventions explicitly, no OCIO color transform on normal/roughness/metallic. Do not treat Material Maker procedural normal as automatically aligned with newly unwrapped UVs. No fabricated normal maps or detail.

Produces candidate.glb with corner-expanded positions, normals, UVs and tangents, embedded sRGB RGBA base color and linear data metallic-roughness (G/B) PNG, optionally bound normal PNG. Also tangent-mesh.npz and tangent.json with source hashes. Source float maps preserved; delivery maps quantized to 8-bit, not lossless HDR. Candidate is unapproved. Run actual Khronos validator; only pass a valid candidate through glTF Transform/Meshoptimizer and approved runtime path. Check seams, mirrored UV islands, silhouette, normal orientation and matched views via LPIPS + visual review before and after optimization. Expanded geometry can be larger; measure, do not promise FPS gains. Basis Universal data-map handling remains separate and requires correct linear sampling and visual checks. Canonical Cycles cover still uses original spatial layers; this stage only prepares an optional static GLB branch, not normal-mapped Sprite Stacking planes. If upstream library unavailable, report blocked; no fake tangents.
