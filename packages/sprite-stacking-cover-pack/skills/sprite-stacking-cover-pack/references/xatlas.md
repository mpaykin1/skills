# xatlas — static hybrid UV bake
Upstream https://github.com/jpcy/xatlas and Python bindings https://github.com/mworchel/xatlas-python (MIT). Install the official bindings `xatlas` with NumPy, SciPy, Pillow in an authorized CPU environment; no substitute algorithm or paid compute. The adapter uses Atlas, PackOptions, vertex mapping and UVs. It rejects multi-page output, missing chart vertices, changed triangle order/winding, invalid UVs and sampled interior overlap. Input is a real static native asset from TRELLIS.2/O-Voxel, Infinigen or its Material Maker variant, verified through Open3D input hash/coordinate checks. Do not use this static adapter to replace skinned/morphing meshes or authored UVs.

`python scripts/xatlas_pack.py --asset /path/native-asset --out /path/uv-candidate --resolution 1024 --padding 8`

Output is a separate candidate: `uv-mesh.obj` (+Z up, native world scale), `uv-mapping.npz` (original vertex mapping, face indices, UVs, coverage), RGBA `baseColor.png`, float `baseColor.npy` and known scalar `roughness.npy`/`metallic.npy` where present, `uv-atlas.json` with source and output hashes. Native source is not modified. Bake samples actual native surface grid at each texel center using nearest sample with a bounded distance of 1.75 native voxel steps; reject uncovered triangles or distant samples rather than invent materials. This is an approximation: thin surfaces, seams, close opposing surfaces and lost source UV detail require visual inspection. Texel-center overlap checks are not a proof of zero continuous UV overlap. Padding extends nearest occupied texels only into unused space; review seams and mip bleeding. Preserve full source PBR, including normal/height/AO/emission; do not claim tangent-space normal transfer, lighting bake, HDR reconstruction or GLB export. Use OpenImageIO/OCIO for explicit high-precision/color conversions of authored source maps; this adapter uses existing LDR grid sRGB straight alpha and Non-Color scalar channels. Do not treat data maps as sRGB.

For a true lighting or source-map bake use the candidate UV mesh in Blender Cycles with reviewed material bindings, original normals and appropriate tangent basis; this is an additional authoring step, not performed automatically. Compare same camera and material against canonical stack and original mesh with LPIPS + visual review; reject changed silhouette, transparency, seam artifacts, material drift. Keep original native grid, PNG layers, pivots and collision data unchanged. Only after review, export a separate static GLB with embedded maps; pass Khronos Validator before/after glTF Transform/Meshoptimizer, and use Basis Universal for compatible color textures with separate validated data-map handling. Existing animated model protections remain. Render the actual canonical cover, not a substituted UV prototype. If xatlas is unavailable, block UV generation; never report synthetic UV fixture as xatlas output.
