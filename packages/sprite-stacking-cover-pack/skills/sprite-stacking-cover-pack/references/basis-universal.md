# Basis Universal — runtime texture delivery

Upstream https://github.com/BinomialLLC/basis_universal (Apache-2.0; check bundled dependency licenses). Three.js loader https://threejs.org/docs/pages/KTX2Loader.html . Install/build upstream basisu in an authorized free runtime. This package does not embed its binary. Use a release and matching Three.js Basis transcoder supporting standard UASTC LDR KTX2; record actual versions. No XUASTC or texture arrays required. Do not assume the newest upstream formats are supported by the game's existing transcoder.

`python scripts/basis_atlas.py --stack path/to/asset.json --out runtime-pages --max-page 2048` makes exact paginated PNGs from canonical bottom-to-top RGBA layers or the existing tiled atlas. Add `--basisu /path/to/basisu` to actually invoke UASTC encoder and validate each KTX2. Four-pixel transparent gutters, block-aligned tile strides, no mipmaps, nearest filtering, texel-center UVs, top-left origin. No downsampling, no geometry changes. Copies preserve original pixels, pivot, spacing, layer indices and source hashes. Canonical PNG layers, native O-Voxel and material sidecars remain authoritative for Open3D/OpenVDB, Cycles and future revisions; libwebp remains the delivery format for animated covers, not spatial textures. Repeat for independent pose stacks; retain shared pivot/grid. Do not treat albedo encoding as encoding of all PBR maps.

`runtime_atlas.mjs` loads exact PNG pages by default and optional KTX2 only when caller explicitly enables `approvedKtx2` after review of these exact hashed files on target devices. Supply the local matching Basis transcoder directory with trailing slash; no paid service or arbitrary CDN required. Both texture types use flipY=false and top-left v=0 UV convention; renderer must map +Y to v=0. Use returned page textures and UV rectangles, batch geometry per page when compatible with correct depth ordering. Validate orientation and alpha on asymmetric slices and real device. PNG fallback on transcode failure; dispose unused textures. Do not mark compressed assets ready by header validation alone.

Compare decoded target texture render with canonical PNG at identical pose, view, lighting and size (LPIPS matched compression pairs with calibrated thresholds, alpha/silhouette comparison and manual inspection). Inspect thin details and semi-transparent areas independently; preserve source on failure. Actual VRAM and FPS must be measured on real mobile; compressed files alone do not guarantee savings. If no acceptable UASTC candidate, use PNG; do not modify the scene to hide artifacts. Do not issue a new cover/chapter merely because texture compression changed.
