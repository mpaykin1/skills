# OpenSubdiv — CPU surface refinement
Upstream https://github.com/PixarAnimationStudios/OpenSubdiv and https://opensubdiv.org/docs/far_overview.html. Build the supplied direct Far API bridge against an installed official OpenSubdiv 3.x C++ CPU library (no GPU requirement). For typical Linux installation: `c++ -O2 -std=c++17 scripts/opensubdiv_cpu.cpp -I/path/to/opensubdiv/include -L/path/to/opensubdiv/lib -Wl,-rpath,/path/to/opensubdiv/lib -losdCPU -o cover-opensubdiv`. Adjust real include/library paths; do not emulate if unavailable. The bridge uses Loop subdivision on triangles, not Catmull-Clark on triangulated cages; it interpolates vertex positions using Far::PrimvarRefiner. No invented anatomical detail, displacement, skin-weight interpolation or UV smoothing. Respect Apache-2.0 with Pixar modification upstream terms; do not redistribute binary here.

For a reviewed static, opaque, closed, single-shell oriented manifold native asset (not animated/skinned/morph, not transparent), run `python scripts/opensubdiv_pack.py --asset /path/native --out /path/subdiv --exe ./cover-opensubdiv --level 1 --static-reviewed --creases /path/edges.json`. Optional edges JSON is a list of existing native index pairs, reviewed hard edges only, e.g. `[[0,1],[1,2]]`; no arbitrary crease indices. Level 1 or 2, triangle budget <=1M. Candidate verifies manifold topology and winding, face count, Euler characteristic, bounding box drift, sampled distance to native grid and tagged-edge sample positions; reject unsafe shrinkage/creases, do not infer anatomical correctness, exact surface distance, self-intersection absence or UV quality. Review actual original and candidate shape under identical camera views with LPIPS/manual evaluation, use Open3D geometry audit/self-intersection checks before adopting a candidate. Native grid, original mesh, RGBA layers, pivot, colliders and existing game remain unchanged. Static opaque surfaces only; avoid smoothing architectural detail without approved creases.

The separate `subdiv-mesh.npz` uses the original native axes; `subdiv-mesh.obj` is +Z up; `subdiv.json` binds original mesh, grid, stack, bridge and candidate by SHA256. Feed the separate candidate into `python scripts/xatlas_pack.py --asset /path/native --subdiv /path/subdiv --out /path/uv-candidate --resolution 1024 --padding 8`. This rechecks source hashes and topology and samples actual original O-Voxel / Material Maker surface channels against the refined triangles, with the same 1.75-voxel bound. If the sample coverage or material alignment fails, retain canonical model. No automatic claim of normal-map or lighting bake. OpenImageIO / OCIO handle original source maps; Cycles renders canonical Sprite Stacking cover. Only after reviewed mesh/material bake, export a separate GLB and run Khronos Validator / Meshoptimizer / glTF Transform, with Basis Universal for compatible textures, LPIPS comparison and existing runtime fallbacks. Do not substitute refined mesh into canonical cover or game without explicit approval and regenerated shared assets. If OpenSubdiv is absent, stop this stage, not the previously approved source path.
