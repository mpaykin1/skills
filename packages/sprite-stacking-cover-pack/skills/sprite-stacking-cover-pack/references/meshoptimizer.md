# Meshoptimizer — hybrid geometry delivery
Upstream https://github.com/zeux/meshoptimizer (MIT); options https://meshoptimizer.org/gltf/. Install official gltfpack in the authorized free runtime. No bundled binary. The current adapter handles static triangular, self-contained GLB models from TRELLIS.2 or Infinigen only; it explicitly rejects skins, morph targets, animations, unsupported extensions and custom vertex attributes. Keep the unoptimized source for these until a verified animation-aware route exists. No simplification of canonical O-Voxel, Open3D, OpenVDB or sprite layers. Source materials and collision/physics proxies remain authoritative.

`python scripts/meshopt_pack.py --source source.glb --out mesh-runtime --gltfpack /path/to/gltfpack --ratio 1` builds a compressed static candidate using -cc -kn -km -ke -noq. For explicitly reviewed optional LOD candidates, repeat into a different output directory with e.g. --ratio 0.75. No automatic LOD switch, no texture transcoding flags. The requested ratio is a target not a guarantee. Original and candidate are stored with SHA256, byte/triangle counts, encoder identity and status review-required. Names and compression extension are checked; this is not a full glTF validator. Never claim equivalence from structure alone.

Use `runtime_mesh.mjs` with the same Three.js release and its MeshoptDecoder. Explicit approvedSHA256 is required before candidate selection; loader checks bytes and falls back to source on failure. KTX2Loader can be supplied by the host when the source uses KTX2. `runtime_atlas.mjs` serves separate Basis sprite pages; it is not replaced. Compare decoded source and candidate renders at identical camera, lights, poses and silhouette (LPIPS compression mode, calibrated limits, alpha and manual review); verify pivots, node transforms, materials, texture orientation, interactive anchors and physics with unchanged collision proxies. Reject any loss of identity or detail. Verify actual browser decode and mobile resource consumption before approval. Render covers from the canonical scene using Cycles and preserve WebP timing; never swap canonical volumes for simplified geometry. Asset ID and source hashes link both delivery branches. No automatic publication or ready claim.

С v0.14.0 обязательна реальная проверка Khronos glTF Validator до и после обработки: [общий технический допуск](gltf-validator.md). При недоступном валидаторе, предупреждениях, ошибках или неизвестных расширениях использовать исходник, не публиковать оптимизированный кандидат.
