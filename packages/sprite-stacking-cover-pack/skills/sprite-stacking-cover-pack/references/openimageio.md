# OpenImageIO — float EXR material interchange
Upstream https://github.com/AcademySoftwareFoundation/OpenImageIO ; Python API https://openimageio.readthedocs.io/en/stable/pythonbindings.html . Install compatible OpenImageIO 3.x in an authorized CPU Python environment. Adapter only; no automatic network install. Original EXR remains immutable, including all subimages and metadata. `oiio_maps.py` reads a selected flat half/float EXR subimage at mip 0 with explicit channel names, exports all channels as float32 NPY and selected material maps; no implicit resampling, tone mapping, clipping or color conversion. Rejects cropped data windows, deep/volume images, nonfinite values and oversized data. No claim of complete multipart interchange: select each part separately. Preserve source, channel mapping and hashes. Example manifest:
```json
{"source":"authored.exr","sourceSHA256":"actual SHA256","subimage":0,"maps":{"baseColor":{"channels":["R","G","B"],"colorSpace":"linear-sRGB","alphaChannel":"A","alphaAssociation":"straight"},"roughness":{"channels":["roughness"],"colorSpace":"Non-Color"}}}
```
`python scripts/oiio_maps.py --manifest input.json --out float-maps` . For baseColor use explicitly declared alpha association (straight/associated, or opaque without alpha); float conversion to straight alpha preserves HDR RGB and does not transform alpha. Use the `baseColor.npy` derivative with `ocio_color.py` and the approved OCIO config for conversion to sRGB PNG where required. Out-of-gamut values require reviewed mapping rather than silent clipping. For Material Maker `maps` entries may be `{"floatManifest":"float-maps/float-maps.json"}` in place of the PNG path. BaseColor must already be sRGB or linear-sRGB within LDR gamut; alpha remains the original native volume alpha. Roughness/metallic are sampled directly as float, never treated as color. Other maps remain retained source material sidecars, not claimed to be shaded by Cycles. HDR emission and density are preserved as float data, not compressed into baseColor or converted into VDB automatically. Use original EXR for authored HDR lighting or baking in Blender with explicit OCIO roles; current Cycles cover script does not shade arbitrary EXR PBR maps. Keep canonical slices for Open3D/OpenVDB/Basis; LPIPS/OIDN compare matching final display renders, libwebp only final sRGB PNGs. No 8-bit intermediate for technical float maps. Review all output before use. If OIIO missing, stop EXR import, no fake decoder. License/provenance checks remain mandatory.
