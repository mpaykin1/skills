# Khronos glslang
https://github.com/KhronosGroup/glslang . Install Ubuntu signed glslang-tools in a disposable worker, record exact compiler version. Canonical script: https://github.com/mpaykin1/skills/tree/nexus/glslang-shader-20261126/packages/skill-synergy-manager/skills/glslang-shader-bridge/scripts . Run `python3 validate_shaders.py /absolute/copy/manifest.json` with real complete vertex+fragment shader pairs, generated for the exact Three.js/WebGL variant. Manifest format: {"pairs":[{"id":"fog-webgl2","vertex":"fog.vert","fragment":"fog.frag","profile":"300 es"}]}. Use explicit #version 100 or #version 300 es; no fabricated stubs, unresolved #include, or Three.js chunks without preprocessing. Preserve generated precision, defines, attributes, varyings and matching material options. Use actual captured source from Spector or renderer debug hooks. Do not modify approved source shaders just for the validator. Do not pass -V or -G for WebGL: SPIR-V validation is a different target. Native Godot/Blender shaders need their own renderer-specific compiler and are not interchangeable with ESSL.
Pipeline: Game Style Forge and META Game Fusion assemble actual GLSL -> glslang CPU syntax/type/link check -> WebGL Lint checks live uniforms, buffers, textures, FBO -> Spector locates actual frame state -> uninstrumented browser verifies visuals/animation/FPS -> RenderDoc only for native compatible capture. glslang success is not WebGL driver success, FPS or image quality. No instrumentation in release. For failures route source GLSL and compiler output to Forge, attributes/GLB to Blender/Fusion, texture/alpha to GIMP/Sprite Stacking. Skill Nexus selects one fix, preserves original hero, rig, physics, input and art; compare same seed/camera/time and reject visual regressions. No change to meta6 or gameplay. Keep prior animated-world/black-screen guards.
