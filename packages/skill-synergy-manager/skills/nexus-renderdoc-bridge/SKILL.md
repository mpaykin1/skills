# Nexus RenderDoc route
Use this module together with Game Style Forge renderdoc-gpu-bridge and nexus-cli-anything; fetch the registry and dispatcher from the linked branch until merged.
Upstream https://github.com/baldurk/renderdoc (MIT); harness https://github.com/HKUDS/CLI-Anything/tree/34f519533bc175d2fe287ab8316b0dd99bb9cc43/renderdoc/agent-harness . Install via Skill Nexus on disposable Ubuntu 22.04 with matching system Python/RenderDoc bindings. Installer and registry: https://github.com/mpaykin1/skills/tree/nexus/renderdoc-cli-20261126/packages/skill-synergy-manager . The registry is not proof of replay availability. Old captures/driver versions may be incompatible; use a matching current RenderDoc version on an authorized GPU workstation when needed. Native .rdc only, no direct WebGL or browser FPS claims. A headless software worker cannot establish phone GPU performance.
For a real authorized capture, use absolute paths and run `cli-anything-renderdoc -c /absolute/frame.rdc --json actions summary`, `actions list --draws-only`, `textures list`, `pipeline state EVENT_ID`. Select actual event ID from action list; optionally use `pipeline diff A B -b /absolute/after.rdc` or `preview capture --recipe quick --event-id EVENT_ID`. Read returned image/JSON files; never assume a successful command fixes graphics.
Feedback: Blender enhancer fixes source mesh, rig, materials and GLB issues; GIMP/stacking skills fix derived texture/alpha without altering geometry; Game Style Forge fixes GLSL, lights, fog and VFX; Godot Game to HTML preserves native scene, original renderer and export; META Game Fusion optimizes draw calls, texture memory and culling without replacing approved heroes. Use original .rdc only with authorization and compatible API/driver. Compare same device, resolution, camera, animation time and quality preset; record native replay limitations. For Three.js browser use existing Playwright screenshots, actual frame probes, renderer.info and supported timer queries separately; never equate RenderDoc draw count to measured FPS. Preserve animated-world and black-screen guards. One measurable fix per iteration; reject regressions in silhouette, alpha, source colors, lighting and controls. No deployment, no protected meta6 edits, no unsolicited reports.
