# Spector.js 0.9.33 — WebGL diagnosis
MIT, https://github.com/BabylonJS/Spector.js/tree/v0.9.33 . Use pinned npm spectorjs@0.9.33 and Playwright in a disposable debug environment, never shipped in the game. Native RenderDoc .rdc remains a separate route. Use only authorized local copies, no secrets or external upload. Capture after actual renderer init and animation startup; initialize spyCanvases before WebGL context creation. Choose game canvas explicitly, not UI/overlay. Capture instrumentation perturbs frame timing; measure normal FPS in separate browser context with no Spector. Mobile emulation is not real device GPU.
Canonical executable tools in this skill: scripts/capture.mjs and scripts/route.mjs. Install dependencies in that directory using package.json, review resolved npm lock and use npm ci after lock is accepted. Run node capture.mjs http://127.0.0.1:PORT/ '#game' capture.json; run node route.mjs capture.json. This local-only script is intended for trusted project servers; redirects/network requests from the page must be separately isolated. Use existing Playwright screenshot and black screen guard; capture is not proof of nonempty visible frames or animation. For worker contexts use upstream explicit spyWorker/captureWorker; this adapter only targets ordinary canvas.
Route findings: shader compilation/link/depth/blend -> Game Style Forge; texture upload/alpha/oversize -> GIMP and Sprite Stacking; draw calls/geometry -> META GAME FUSION + Blender + glTF-Transform; native replay -> RenderDoc; actual animation identity and full poses -> Hero Animator/animation-quality. Maintain source hash, camera, seed, animation phase, resolution, quality tier. Re-run same scenario on a copy and reject fidelity/controls/animation regressions. Never change Rapier authoritative physics or protected meta6. Do not claim improvement percentages without measured comparable frames. No unsolicited reports or evidence artifacts in game releases. Keep capture data private in temporary development environment.
Upstream also has a separate Spector MCP server (mcp/README.md), not installed or connected by this bridge. Do not claim MCP availability.
