# Khronos glTF Validator — v0.8.0, mandatory 3D release gate

All commands in this skill are relative to sibling `skills/animation-quality/` (not this companion skill directory). Read the current main SKILL.md and the relevant Rigify/Animation Layers skills before editing. This gate is mandatory for GLB output across all 3D routes, including layered skeletal motion; contact comparison remains necessary even when the official validator succeeds. Mantaflow and Effekseer effects retain their native checks; validate GLBs if geometry is exported, and apply OpenCV/Pillow/FFmpeg only to derived rendered effects. No changes to existing skills or their constraints.


Official KhronosGroup/glTF-Validator, Apache-2.0, npm `gltf-validator@2.0.0-dev.3.10` (https://github.com/KhronosGroup/glTF-Validator; https://www.npmjs.com/package/gltf-validator). Use Node 20+ and install the exact dependency with `npm install --ignore-scripts --no-audit --no-fund` from this skill directory; no unpinned upgrade. Package code is not bundled. No silent substitute for official validation. CPU, no GPU. `scripts/khronos_validate.cjs` invokes real `validateBytes` with all issues enabled; checks version, rejects errors, truncated reports, unsupported extensions and IO errors. `scripts/gltf_gate.py` supports self-contained GLB up to 256 MiB, blocks external resource loading and compares SHA-256 of the exact validated bytes. `python scripts/gltf_gate.py validate MODEL.glb [--strict]` is mandatory before and after 3D export; strict additionally rejects any warning. JSON glTF/external assets must be packed separately with verified source protection before using this gate. Do not overwrite originals.

Root-motion route: validate original GLB -> original .blend and previous `blender_root_worker.py` (SciPy solver, explicit contact locks) -> export candidate GLB with identical layout/settings -> `python scripts/gltf_gate.py compare-root BEFORE.glb AFTER.glb --clip 0 --node 0 --radius 0.03 --anchors 20 21 22 --confirm-contact-samples` (example values only; use the actual animation/node indices, world-unit radius in exported GLB coordinates, and all contact sample indices, zero-based; explicitly verify root axes, units and contacts). Both GLBs are validated independently, new warning codes/pointers forbidden. Protected comparison restricts core glTF to one unparented root LINEAR translation channel with exclusive dense float accessors/views, checks exact JSON except changed accessor min/max and exact binary bytes outside that accessor, preserves geometry, UVs, material images, skin, other channels, timestamps, clips, endpoint and contact samples. SciPy/NumPy compare jerk and acceleration in physical time and require real improvement within deviation bounds. No claim of semantic identity from validator alone. Re-export layout changes, extensions, quantized tracks, shared accessors, nonuniform sampling or different node indices are deliberately blocked, not silently permitted. Do not loosen guard for passing. For other 3D changes validate both GLBs but require separately scoped semantic comparison and visual approval; this root-only gate does not authorize edits to bone poses or meshes.

Then render matched camera views from actual approved 3D source; OpenCV checks motion discontinuities, Pillow preserves original RGBA rendered poses, NumPy measures quality, FFmpeg optimizes verified delivery formats. For volumetric sprite stacking regenerate real horizontal slices from evaluated poses using existing grunge skill; protect unchanged source. RIFE and Bitmapflow remain restricted to authorized nonorganic effects/sprites, never characters. Validator errors route back to Blender/asset export rather than to frame interpolation or FFmpeg. No release claiming complete repair until actual 3D validation and visual review succeed. No user-facing report unless requested.

Local verification: independent protected-comparison path exercised using synthetic 48-sample GLBs (accepted smoother root motion, rejected changed metadata and locked sample); missing npm package correctly blocked validation. Earlier integrations remain unchanged.
