# DeepLabCut — custom anatomy v0.10.0
Official DeepLabCut 3.0.1 (LGPL-3.0): https://github.com/DeepLabCut/DeepLabCut/releases/tag/v3.0.1 . API and CSV contract: https://deeplabcut.github.io/DeepLabCut/docs/standardDeepLabCut_UserGuide ; https://deeplabcut.github.io/DeepLabCut/dev/main/reference/deeplabcut/compat/ . Use isolated CPU environment and trusted, locally trained/evaluated single-creature PyTorch checkpoint. No bundled model, no automatic download, no automatic training claim. Training custom landmarks requires representative labeled frames (all intended angles, actions, occlusions) and validation on held-out sequences; do not assume generic SuperAnimal knows fictional monster anatomy. Keep MediaPipe for supported humanoids; FreeMoCap/Rokoko for actual human motion capture and retarget, not inferred monster skeletons. No direct retarget of 2D points.

1. Define exact creature ID, view, original animation and fixed named parts/triples (e.g. hip, knee, ankle; creature-specific, no invented points). JSON schema: {"parts":["hip","knee","ankle"],"joints":{"leg":["hip","knee","ankle"]}}. Include all required joints. Render full original and candidate in the SAME fixed orthographic camera, canvas, constant FPS, frame count and motion timeline, same lighting/background. Each yaw is separate, never compare across yaw or different animation actions. Use lossless render/video preparation via FFmpeg; check timestamps with ffprobe; no resampling variable-duration GIFs to fake matched frames. Use approved original RGBA assets, never replace poses. Validate actual project/checkpoint identity and training provenance separately, including same checkpoint hash across captures.
2. In isolated environment use official `deeplabcut==3.0.1`, PyTorch CPU backend, OpenCV, NumPy, SciPy; existing dependencies separately as needed. `python scripts/dlc_motion.py capture CONFIG.yaml BEFORE.avi NEW_DIR --confirm-trusted-trained-single-creature-project`; same config, shuffle and checkpoint for candidate. Calls upstream analyze_videos, exports one single-animal CSV and source hash metadata. No native inference ran in authoring environment; model/project not supplied and DLC package absent. If API or checkpoint unsupported, stop, never fabricate detections. Capture only from authorized models and trusted configurations. Metadata verifies file pairing, not cryptographic proof of model execution. No multi-animal ID matching.
3. `python scripts/dlc_motion.py compare BEFORE.avi AFTER.avi BEFORE.csv AFTER.csv BEFORE/capture.json AFTER/capture.json schema.json --mode loop --confirm-same-creature-camera-cfr-timeline-model` (once for nonloop). Fixed confidence >=0.8; >=90% matched angle coverage; candidate cannot lose valid baseline samples. No interpolation of occlusions. NumPy computes projected angles, SciPy robust dispersion, acceleration RMS and p95 including loop seam. OpenCV forward/backward LK provides independent pixel-motion agreement with DLC. Insufficient optical coverage or increased discrepancy is a review blocker; never interpret low disagreement as anatomical correctness. Compare raw coordinates, visual contact and intended dynamics, not simply lower acceleration. Legitimate strikes/landings must remain sharp. Proxy only: no 3D angle, contact, pose quality or artistic percentage inferred from 2D.
4. Route identified suspicious joints/frames to Blender / Rigify / Monster Anatomy 3D, preserving mesh, rig, textures and original actions. Apply only reviewed actual 3D corrections through existing Animation Layers, SciPy root solver only in its permitted domain, compare_contacts and rigify motion_gate; never smooth organic GIF pixels via RIFE/Bitmapflow. Rerender approved original and candidate same view and rerun DLC+OpenCV. Khronos gate protects GLB; Sprite Stacking uses complete evaluated pose volumes, not flat warp. Pillow/FFmpeg package only after original visual/identity, contact, timing and completeness checks pass. Keep previous integrations unchanged. No automatic artistic PASS; if no trained model, no runtime or no matched renders, explicitly blocked. Provide actual improved visuals only when produced.
