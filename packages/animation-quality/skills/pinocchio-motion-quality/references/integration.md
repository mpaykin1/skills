# Pinocchio integration 0.13.0
Official BSD library https://github.com/stack-of-tasks/pinocchio ; Python API https://gepetto.github.io/doc/pinocchio/doxygen-html/ ; install official distribution `pin` https://pypi.org/project/pin/ (NOT the unrelated PyPI `pinocchio`). Use an isolated CPU Python environment with a reviewed exact compatible version and record `importlib.metadata.version('pin')`; NumPy and SciPy must be compatible. No automatic downloads. The package was unavailable in authoring runtime, so no native execution claimed.

## Pipeline
1. Use trusted authored fixed-base URDF calibrated to actual source rig, metres, kilograms, seconds, native rad/m scalar bounded revolute/prismatic joints only. No floating root, continuous quaternion joints, mimic constraints, unknown external plugins or human surrogate for monsters. This bridge does not create URDF from GLB/GIF. For free-moving full-body creatures use existing MuJoCo/OpenSim routes; no forced substitution. Inertial and gravity parameters must be independently reviewed before unloaded inverse dynamics. No ground reaction or actual torque claims from unloaded RNEA.
2. Export original evaluated Blender/Rigify motion as CSV `time,<exact native joint names>` on the original CFR timeline. Use actual calibrated 3D reference markers from FreeMoCap/OpenSim or source rig (latter only a parity reference); MediaPipe/DeepLabCut single-view 2D is diagnostic, not metric 3D. Author explicit corresponding Pinocchio named frames, transform reference into URDF world coordinates, record source identity, SHA and mapping. Do not invent markers or contacts. The JSON reference schema uses `hero_id`, `clip`, `units:"m"`, `axes:"urdf-world"`, `time:[...]`, `frame_names:[...]` (>=3 distinct frames), `positions:[N][M][3]` actual calibrated values. No direct conversion of coordinate names or units between models; author and review mapping. Matching reference time must be exactly the CSV times.
3. `python scripts/pinocchio_motion.py MODEL.urdf SOURCE.csv REFERENCE.json SPEC.json` invokes native forwardKinematics and updateFramePlacements; optional unloaded RNEA only for fixed-base no-contact clips with reviewed inertias/gravity. Explicit spec fields: rights_confirmed=true, mapping_reviewed=true, mode="once", units="native-rad-m", model_sha256, motion_sha256, reference_sha256, hero_id, clip, anchors (authored frame indices), contacts (array of {start,end,marker_index} inclusive, marker_index into reference names); if none, no_ground_contact_confirmed=true. Optional unloaded_inverse_dynamics_confirmed=true and inertia_and_gravity_reviewed=true only if physically justified. A marker drift metric is not collision or balance simulation. Per-joint demand remains separate per native unit, not mixed into a global score.
4. For explicitly unintended jitter only, add `--output CANDIDATE.csv` with spec confirm_unintended_jitter=true, edited_joint exact name, radius_native (0 < radius <= .05 rad/m). Calls existing OpenSim module's real SciPy bounded sparse least-squares solver, preserving original input, all other joints, exact contact/event anchors and endpoint samples, same frame times. Reject acceleration/jerk non-improvement, out-of-range joints, marker RMS/p95 regression per marker, contact drift, and unloaded inverse-demand regression per joint (1% numerical tolerance). No attacks, jumps, deliberately abrupt movement, loops, new poses, or root corrections in this route. Native package required before output; no fallback to unverified metrics. Candidate not approved final animation. Compare baseline absolute quality independently.
5. Transfer accepted candidate to actual source rig only through reviewed existing Rokoko/Rigify/Animation Layers workflow; do not change topology, textures, skin or other actions. Map back to calibrated OpenSim and MuJoCo states if applicable; run existing native marker/contact/physics gates before acceptance. No automatic conversion between their coordinate systems. Pinocchio is an offline quick gate for supported models, MuJoCo handles actual contact dynamics diagnostics, OpenSim checks anatomical references. Re-render full original-volume poses and eight directions from same source, with OpenSubdiv if already authorized. Use OpenCV/MediaPipe/DeepLabCut for visual review, Khronos GLB validator for 3D structure, Pillow/FFmpeg exact frame delivery. Existing RIFE/Bitmapflow restrictions unchanged; NanoVDB/OpenVDB/Mantaflow/Effekseer unchanged. No visual percent from proxy metrics, no extra reports unless requested.
