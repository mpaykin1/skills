# MediaPipe Pose Quality v0.9.0

Official google-ai-edge/mediapipe (Apache-2.0), pin 0.10.32 from PyPI; Pose Landmarker Tasks Python API: https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker and https://developers.google.com/edge/api/mediapipe/python/mp/tasks/vision/PoseLandmarker . The model `.task` must be separately acquired from the official model source, with license verified and SHA256 recorded from a trusted copy. No model weights bundled. Install MediaPipe in a separate CPU virtualenv with compatible existing Pillow, NumPy, OpenCV and SciPy dependencies; avoid installing competing OpenCV wheels into the production environment. If dependencies or model missing, fail closed; never claim real landmark inference. No network calls by the worker.

## Cooperative pipeline
1. Read the base Animation Quality SKILL.md and use existing `quality.py audit ... --flow` for all clips. MediaPipe is optional and only for clearly visible single human/humanoid full-body clips in a fixed camera. For nonhuman monsters, obscured bodies, exaggerated anatomy, rotated views, static objects, multiple people, and uncertain detections use actual Blender rig data/Monster Anatomy 3D and OpenCV instead. Do not force a human skeleton on creatures. Use original rendered poses, no Bitmapflow/RIFE on organic figures. Never manufacture missing poses or declare foot contact using estimated landmarks.
2. Preserve original asset and compare a separately rendered candidate with exactly the same camera, canvas, frame count, playback durations and loop flag. Use the existing Blender/Rigify/Animation Layers authoring path to correct reviewed joint issues and lock independently authored support contacts; use SciPy root solver only for its allowed root-jitter domain, never to adjust landmark pixels, drive bones or convert 2D to 3D. For Sprite Stacking rerender genuine full-volume poses from the same rig and preserve all original slice geometry. Audit per view, never combine unrelated cameras. Run Khronos gate before and after GLB changes; missing validator blocks that route.
3. Run from the skill root:
`python ../animation-quality/scripts/mediapipe_pose.py ORIGINAL.gif CANDIDATE.gif --model /trusted/pose_landmarker_full.task --sha256 TRUSTED_SHA256 --mode loop --background 32 --confirm-single-humanoid-same-camera-same-timeline`
For one-shot use `--mode once`. Dark/light background is fixed across both clips; choose contrast appropriate to artwork. Pillow decodes frames/disposal, NumPy composites alpha to a detector-only background (never mutates source), MediaPipe IMAGE mode detects 33 landmarks independently per frame (no temporal tracker masking jitter), SciPy computes robust MAD, NumPy evaluates projected elbow/knee/hip/shoulder angular acceleration with actual frame time and cyclic seam. Visibility and presence >=.75, no offscreen joints, no multi-person matches, no lost baseline detections, >=90% matched angles and >=80% matched derivative samples. Do not fill missing landmarks with fabricated poses. OpenCV full audit is included for both inputs. Evaluate model confidence and visually inspect outliers, intended movement, contacts, and identity. 2D angles are camera-dependent proxies; a lower acceleration may merely mean less movement or detector bias. Do not treat any metric as an artistic quality percentage or automatic approval.
4. For final assets compare original/candidate with full prior gates and manual artistic review; reject if genuine motion/identity/contacts regress. FFmpeg delivery optimization only after approval, retaining pixel/timeline guards. Existing Bitmapflow/RIFE effects routes, Mantaflow/Effekseer, Rigify/Animation Layers, glTF checks unchanged. No automatic skin/mesh deformation, pose synthesis or MediaPipe retarget. Deliver assets when actually improved, not logs unless requested.
