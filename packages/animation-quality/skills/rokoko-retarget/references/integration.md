## Producer — Blender Model Animation Enhancer
1. On an isolated free Blender 4.5 worker, obtain the pinned official repository from the link above; review its dependency downloads, login and updater before enabling. `python scripts/stage_rokoko.py --source /reviewed/local/clone --out /new/rokoko.zip` verifies exact Git commit, clean tree and license blob and creates the unmodified addon ZIP. It does NOT install or run Blender. Install via supported Blender addon UI/CLI after review, use official authentication if required. Never provide credentials in configuration or bypass an account gate. No native install confirmed here.
2. Use authorized source skeletal animation (BVH/FBX or actual FreeMoCap export with rotations, not raw marker positions; Open Mocap alternative). Import into disposable copy of approved 3D source scene. Keep raw footage private. Fit source and target to matching reference pose, correct axes, scale, handedness, joint names. Source action and transfer skeleton must have verified provenance. For Rigify, use a separately prepared unconstrained transfer armature, not blind writes into DEF bones, control bones or a constrained skinned rig. Transfer the reviewed result to the actual approved Rigify controls via existing IK/FK authoring and Animation Layers; this adapter does not automatically perform that second step.
3. Config: rights_confirmed, mapping_reviewed, rest_pose_reviewed, fk_target_reviewed all true; source_sha256 (working blend), motion_sha256 (licensed motion file), hero_id, source_rig, target_rig, source_action, new_action, clip, fps, start/end inclusive frames, pose REST or CURRENT, auto_scale boolean, root_mode in_place or world (requested later policy, not auto root stripping). mapping array of {role,source,target}, required hips/spine/chest/neck/head and left/right upper_arm/forearm/hand/thigh/shin/foot (suffix _l/_r), exact actual bone names; optional toes/clavicles/fingers. `python scripts/map_gate.py config.json` validates structure; does not prove anatomical correctness. No duplicate target or source bones. Use only actual approved mappings, not name guessing.
4. `blender --background approved-copy.blend --python-exit-code 1 --python scripts/retarget_rokoko.py -- --config map.json --motion source.bvh --out new-transfer.blend` invokes the registered official `rsl.retarget_animation` operator if available in the authorized context. Use isolated profile with operator installed and authorized. If headless unsupported, use official UI, same reviewed mapping, save separate copy. No private API, account bypass, automatic login or unreviewed install. Source SHA and timing checked; output action is a transfer draft. Preserve actual original rig, mesh, skin, materials, costume and sword. No synthetic animation substitute.
5. Transfer evaluated rotations to the approved Rigify IK/FK controls, correct poles/hips/twist, root motion and foot contacts in native NLA Animation Layers. Use existing `rigify-hybrid` and `animation-layers-hybrid` sampling, exact `source_sha256`, `hero_id`, `layer_recipe_sha256`, frame indices and FPS in every volume and attachment. Required idle/walk/run, backwards locomotion separate from walking away, jump_start/jump_loop/jump_land, light/heavy/air_attack. Actual authored events only; add reviewed contacts and sword grip. Rapier owns movement; remove root double motion for in-place clips, verify floor contacts and speed. No automatic attack or movement from animation. No percentage improvement without actual baseline/render.

## Consumers — Hero Animator / META Game Fusion
Only consume approved full RGBA poses or complete XY slices from same evaluated 3D character, not morphing original sprites; never replace approved 2D artwork. Use prior `rig-sync.mjs`, `layer-sync.mjs`, full-frame and volume guards. GLB sword/attachment transform and all views use same frame/pivot. Effekseer receives unique authored hit/takeoff/land cues after real input and physics; no damage authority. Mantaflow continuous fire/smoke, Quarks ambient particles, GLSL/PostFX shading, Black Screen Guard. No Rokoko service inside the game or duplicate animation loops.

## Quality — Animation Quality
Run map_gate on source config then existing motion_gate and compare_contacts on actual evaluated Rigify baseline/final. Confirm root policy, matching timing, 8 yaw views (rear especially), natural pelvis/shoulder counter-motion, knee/elbow directions, foot sliding, jump landing, separate air attack, fixed weapon grip and material/identity consistency. Retargeted animation is not automatically a valid hybrid volume; all existing frame approval, glTF Validator and visual checks remain mandatory. No runtime or approved assets means BLOCKED, no visual PASS. No reports unless requested.
