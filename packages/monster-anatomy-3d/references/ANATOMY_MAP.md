# Reference sketch anatomy map

Observed silhouette: roughly humanoid, forward-hunched spine, oversized dorsal/shoulder mass, bald skull thrust forward, elongated arms ending in long claws, narrow ribcage, oversized posterior thigh and skinny shin/calf, crouched asymmetrical predatory pose. Grayscale pencil-clay material.

| Region | Structural notes | Deforming muscle focus |
| --- | --- | --- |
| Skull/neck | Small cranium, projected cervical chain, strong occipital ridge | sternocleidomastoid/trapezius analogues |
| Shoulder/back | High hump built on enlarged scapular girdle, not a floating bulge | broad scapular stabilizers, latissimus, deltoid |
| Torso | Short cage with compressed waist/forward chest | pectoral, serratus, external oblique |
| Arm | Scapula→humerus→radius/ulna, elbows capable of extreme flexion | biceps, triceps, brachialis, forearm groups |
| Hand | Elongated phalanges and claws with independent hinges | flexor tendons extending to digit tips |
| Hip/thigh | Pelvic anchor behind torso, exaggerated hip rotation | gluteal, quadriceps, hamstrings |
| Leg/foot | Stable bent knee, raised heel, stretched toe/claw | calf and Achilles-like tendons |

**Action anatomy:** Idle visible breathing under ribcage, neck scan and finger curl. Stalk plants toes before hip travel; pelvis and shoulder counter-rotate. Attack drives shoulder and elbow toward target with full upper-body recovery; all motions use bone transforms, never global mesh squash.

**Uncertainties:** Photo/sketch is a single view; the other side, occluded pelvis, missing fingers and exact muscle attachment sites require design decisions. Distinguish design hypotheses from real biological anatomy.
