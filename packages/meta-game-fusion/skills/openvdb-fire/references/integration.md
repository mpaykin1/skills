# OpenVDB fire bridge
Upstream https://github.com/AcademySoftwareFoundation/openvdb/tree/e4621ae7b37d993ffb93f11ded327736b8227f5f (v12.1.0, Apache-2.0, LICENSE Git blob d9a10c0d8e868ebf8da0b3dc95bb0be634c34bfe). OpenVDB stores/processes sparse volume grids; it does not simulate fire. Mantaflow remains solver. OpenVDB Python module `openvdb` built with NumPy support, NumPy and Pillow are external dependencies. Use a reviewed distribution package or build this pinned release on isolated worker with its documented CMake options; inspect license/dependency versions and verify package hash independently before installing. Do not auto-install unreviewed PyPI substitutes. Neither native OpenVDB nor Blender is bundled. Install through the actual worker, not a fake CLI. This source integration has not been exercised with real VDB inputs.

## Producer
Use existing mantaflow-fire/bake_mantaflow.py (Blender 4.5 LTS, OPENVDB cache, fixed domain). Keep source caches immutable. Inspect grid names and transform with `openvdb.readAllGridMetadata` on the worker; select actual consecutive density/flame grids, in the same VDB file per frame. If high-resolution noise files have incompatible names/transforms, use matched base grids or explicitly resample upstream; never guess names or concatenate unrelated grids. Select a fixed crop enclosing the entire plume at all times with margins, positive axis-aligned isotropic transform, no adaptive changing domain. Use approved cache bytes only; isolate native parser from secrets and bound worker resources. A crop-edge check is not proof of full uncropped domain; review source bounds. Config JSON beside cache: `source: blender-mantaflow`, `origin:[i,j,k]`, `shape:[nx,ny,nz]` (8..96), `stride:1..4` divides dimensions, `density_grid`, `flame_grid` (exact names), `fps:24`, `frames:[{frame:49,file:"cache/data/file.vdb",sha256:"actual SHA256"},...]` (16..64 consecutive entries), optional extinction/emission (art-directed). Run `python scripts/pack_volume.py config.json NEW_DIR`. Requires native OpenVDB API; no synthetic substitution. Reads scalar float grids via copyToArray with fixed origin, validates transforms and finite values, averages downsampled blocks, shades RGBA in Three.js axes (Blender x,y,z -> x,z,-y), max dimension 64 and total raw 32 MiB. Produces real per-frame RGBA volume cross-sections in z,y,x byte order (x fastest), fallback PNG atlas projected along +Z from same volume, `volume.json` with hashes, time and light curve. Fallback is one view, not full 360; use existing multi-view rendering pipeline if needed. Shading approximates absorption/emission, not physically accurate light transport. Preserve true volume, not flattened repeated planes. Do not call this a Mantaflow simulation if input provenance is missing.

## Consumers
Use existing scene update loop and `runtime/volume-runtime.mjs`. Load pack bytes and PNG bytes; validate metadata and verify both SHA256 before decoding/using. `createVolume(THREE,renderer,scene,verifiedArrayBuffer,meta,worldBasePosition,{phase,scale,light})` uses bounded WebGL2 Data3DTexture, transparent raymarch box (96 steps) and a single optional dynamic lamp. Caller owns shared clock, calls update(seconds), disposes on scene change. Base position is chosen by scene author to align with the fuel source; do not mistake VDB source coordinates for game placement. The box has approximate opaque-depth occlusion (back-face depth test, not per-sample depth); mount outside solid surfaces, visually review intersections and use approved fallback if clipping occurs. Do not start another RAF or simulate collisions from fire sprites. Rapier/BVH own physical geometry. Existing Sprite Stacking uses real volume slices for solid actors/props; transparent fire is a separate volume layer with no depth write. Use Mantaflow baked flipbook OR the OpenVDB volume (not duplicate continuous plumes), Effekseer for event bursts, Quarks for ambient ash/embers, GLSL/PostFX for heat haze and bloom. No duplicate lights, particle systems or action clocks. Maintain bounded active plume count (desktop <=3, mobile <=1 volume, lower tier fallback) and budget FPS. Black Screen Guard: keep animated fallback visible until valid GPU frame; on error/context loss/slow device use `drawFallback` with same time and phase and verified decoded image, no static flame. Check actual browser frame motion, mobile orientations and off-line assets. No game publication claim without real playback.

## Quality
`python scripts/audit_volume.py PACK` validates hashes, sizes, nonempty changing volume and projected frames, seam and bounded memory. It is not a physical accuracy or artistic certification. Compare actual fire silhouettes across frames and camera directions, smoke movement, reflection/light, car occlusion and fallback. Static photograph plus moving sparks is failure. No percentage of improved game quality without real comparable renders. Preserve all prior Rigify/Animation Layers/OpenSubdiv/character and black-screen guards.
