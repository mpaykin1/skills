# Effekseer combat bridge v1
Upstream MIT runtime: https://github.com/effekseer/EffekseerForWebGL ; pinned distribution candidate 1.80.3 from official README https://github.com/effekseer/Effekseer/releases/download/1803/EffekseerForWebGL1.80.3.zip . Native editor/runtime not bundled or installed by this source adapter. Download only from official release on an authorized worker, record SHA256 and license, unpack isolated; verify actual wasm init and authored .efkefc dependencies. No CDN for standalone games. Do not claim installation from documentation.

Producer: author effects in Effekseer editor, retain .efkefc and all licensed dependencies, export transparent numbered PNG sequence (zero-padded order), run `python scripts/pack_effect.py INPUT_DIR NEW_OUTPUT --fps 30` with Pillow and NumPy. Keep originals. Required separate effects light_slash, heavy_slash, air_slash, jump_burst, landing_dust, hit_sparks. Pack checks changing RGBA and bounded dimensions; inspect actual motion and artist approval. These are VFX, not character animation or true volumetric stacks. Mantaflow stays sole continuous fire/smoke provider; Quarks owns ambient embers/ash; Effekseer owns short combat bursts only.

Consumer: copy `runtime/combat-vfx.mjs` into project. Validate atlas bytes with verifyAtlas before decode, check image dimensions, retain approved .efkefc. For native path initialize pinned legacy API with effekseer.initRuntime then createContext and init(renderer.getContext()); preload effects using loadEffect callback before combat, keep GL state restoration on. Pass initialized native context, asset map (duration in seconds from atlas metadata; effect handle optional), monotonic simulation clock, spawnBaked callback to createCombatVFX. Baked callback can use bakedThree(THREE,scene,texture,meta,pos,scale) or existing canvas 2D list with drawCombat2D; immediately update to supplied age. Never create second RAF. emit({id,cue,position:[x,y,z]}) only from authoritative animation hit marker or Rapier takeoff/landing event, unique event ID per action occurrence. XState/bitECS if present owns event distribution; no VFX triggers player movement or damage. tick(dtSeconds) once per frame; draw(renderer,camera) after opaque scene render, before bloom if verified composer pass integration; otherwise explicitly use bakedThree within existing scene/composer. On context loss invoke contextLost and keep 2D rendering visible using same assets. Dispose on scene teardown. Max 24 concurrent bursts, lower on mobile; never duplicate native and baked effect. Native draw failures fall back, renderer.resetState restores Three.js cache. No fake effects if asset absent.

Quality: inspect actual front/back/side pose and attack separately, compare cropped VFX frames with locked camera, check timing against actual contact markers (<= one rendered frame), distinguish takeoff and land, test GPU unavailable and context loss. No missing air attack hidden with VFX. No static fire from this bridge. Preserve rig, body slice poses, costume and sword geometry. This integration does not fix walk cycles; route them to Blender rig/mocap workflow. No claims of full runtime PASS before real browser playback. Adapter can run without upstream runtime only when real exported frames exist.
